LAB 06 · QUESTION 01

Triangular numbers

Write a Java method that returns a triangular number. A triangular number is defined as 1 + 2 + 3 + … + n. Then, write a Java program to use the method to display the first 20 triangular numbers.

The first 20 triangular numbers
    1    3    6   10   15   21   28   36   45   55
   66   78   91  105  120  136  153  171  190  210

Output of the model. The worksheet gives no sample run; these values are fixed.

The 20 values the program prints

Model IPO and pseudocode

Method input: n. Process: add 1 to n. Method output: the sum, returned to the caller. The program calls the method 20 times and prints each value.

METHOD triangular(n)
    SET sum = 0
    FOR i = 1 TO n
        sum = sum + i
    RETURN sum
END METHOD

START
FOR n = 1 TO 20
    DISPLAY triangular(n), 10 values per line
END
Reveal complete JDK 27 program
public class TriangularNumbers {
    // Precondition: n >= 1.
    // Postcondition: returns the nth triangular number, 1 + 2 + ... + n.
    public static int triangular(int n) {
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        return sum;
    }

    public static void main(String[] args) {
        System.out.println("The first 20 triangular numbers");
        for (int n = 1; n <= 20; n++) {
            System.out.printf("%5d", triangular(n));
            if (n % 10 == 0) {
                System.out.println();
            }
        }
    }
}
The method computes one value and returns it; main decides how to display it. That separation lets you reuse and test the method on its own: triangular(4) must be 10. The formula n(n + 1) / 2 gives the same values without a loop; the loop follows the worksheet's definition. An int holds every triangular number up to n = 65535.

multiPrint input: a count and a character; output: that many characters on the current line. Each shape method decides how many spaces and stars each row needs, then ends the line.
METHOD multiPrint(n, c)
    REPEAT n TIMES: DISPLAY c (no line break)

METHOD centredTriangle(size)
    FOR row = 1 TO size
        multiPrint(size - row, ' ')
        multiPrint(2 * row - 1, '*')
        end the line

import java.util.Scanner;

public class MultiPrint {
    // Precondition: none; nothing is printed when n <= 0.
    // Postcondition: prints n copies of c on the current line, without a line break.
    public static void multiPrint(int n, char c) {
        for (int i = 0; i < n; i++) {
            System.out.print(c);
        }
    }

    // Precondition: size >= 1.
    // Postcondition: prints a right-angled triangle; row r has r stars.
    public static void rightTriangle(int size) {
        for (int row = 1; row <= size; row++) {
            multiPrint(row, '*');
            System.out.println();
        }
    }

    // Precondition: size >= 1.
    // Postcondition: prints a centred triangle; row r has size - r spaces and 2r - 1 stars.
    public static void centredTriangle(int size) {
        for (int row = 1; row <= size; row++) {
            multiPrint(size - row, ' ');
            multiPrint(2 * row - 1, '*');
            System.out.println();
        }
    }

    // Precondition: size >= 1.
    // Postcondition: prints a diamond 2 * size - 1 rows high: the centred triangle,
    //                then the same rows upside down without repeating the widest row.
    public static void diamond(int size) {
        centredTriangle(size);
        for (int row = size - 1; row >= 1; row--) {
            multiPrint(size - row, ' ');
            multiPrint(2 * row - 1, '*');
            System.out.println();
        }
    }

    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter the size: ");
        int size = keyboard.nextInt();
        if (size < 1) {
            System.out.println("The size must be at least 1.");
            return;
        }

        System.out.println("Triangle");
        rightTriangle(size);
        System.out.println("Centred triangle");
        centredTriangle(size);
        System.out.println("Diamond");
        diamond(size);
    }
}
multiPrint does one small job and does not end the line, so its caller decides when to call System.out.println(). Row r of the centred triangle needs size − r spaces and 2r − 1 stars: check this on paper for size 4 before coding. The diamond reuses centredTriangle for its top half, because a method can call another method. multiPrint(0, ' ') prints nothing, which is exactly what the widest row needs.

Reverse the integers in an array
Write a Java method that accepts an array of 10 integers. The method should reverse the integer in the array. Example, if the number is 1234, the number will change to 4321.

Model IPO and pseudocode
reverse input: one non-negative int; output: its digits reversed. reverseAll input: the array; it returns nothing but replaces every element through the shared reference.
METHOD reverse(number)
    SET reversed = 0
    WHILE number > 0
        reversed = reversed * 10 + number % 10
        number = number / 10
    RETURN reversed

METHOD reverseAll(numbers)
    FOR i = 0 TO numbers.length - 1
        numbers[i] = reverse(numbers[i])

START
FILL numbers[10] with random integers from 0 to 9999
DISPLAY numbers
reverseAll(numbers)
DISPLAY numbers
END

import java.util.Random;

public class ReverseDigits {
    // Precondition: number >= 0 and its reverse fits in an int.
    // Postcondition: returns the digits of number in reverse order (1234 -> 4321, 1200 -> 21, 0 -> 0).
    public static int reverse(int number) {
        int reversed = 0;
        while (number > 0) {
            reversed = reversed * 10 + number % 10;   // append the last digit
            number /= 10;                             // remove the last digit
        }
        return reversed;
    }

    // Precondition: numbers has 10 elements, each meeting the precondition of reverse.
    // Postcondition: every element is replaced by its reverse. The caller's array changes,
    //                because the method receives a copy of the reference to the same array.
    public static void reverseAll(int[] numbers) {
        for (int i = 0; i < numbers.length; i++) {
            numbers[i] = reverse(numbers[i]);
        }
    }

    // Postcondition: prints the label and the elements on one line.
    public static void printArray(String label, int[] numbers) {
        System.out.print(label + ":");
        for (int i = 0; i < numbers.length; i++) {
            System.out.print(" " + numbers[i]);
        }
        System.out.println();
    }

    public static void main(String[] args) {
        Random random = new Random();
        int[] numbers = new int[10];
        for (int i = 0; i < numbers.length; i++) {
            numbers[i] = random.nextInt(10000);   // 0 to 9999
        }

        printArray("Before", numbers);
        reverseAll(numbers);                       // no return value: the array itself changes
        printArray("After ", numbers);
    }
}
reverseAll is void, yet main sees the change: the method receives a copy of the reference, so both lead to the same array (Week 7, pass-by-value). Each element is reversed by a separate method, reverse(int), which you can test alone. The worksheet does not cover these cases, so the model states them: trailing zeros disappear (1200 → 21, because 0021 is the int 21); 0 stays 0; one digit is unchanged. The precondition asks for non-negative values; for a negative number you could return -reverse(-number). A 10-digit int can overflow when reversed: 1999999999 reversed does not fit in an int.



LAB 06 · QUESTION 04
GCD by the Euclidean algorithm
Write a Java method that implements Euclidean Algorithm to return the greatest common divisor of two positive integers. Then, write a program to get the GCD for (24, 8) and (200, 625).
GCD(24, 8) = 8
GCD(200, 625) = 25
Output of the model for the two pairs in the worksheet.
Stepabremainder = a % b
Model IPO and pseudocode
Input: two positive integers. Process: replace (a, b) by (b, a % b) until b is 0. Output: a, the greatest common divisor.
METHOD gcd(a, b)
    WHILE b ≠ 0
        remainder = a % b
        a = b
        b = remainder
    RETURN a

START
DISPLAY "GCD(24, 8) = " and gcd(24, 8)
DISPLAY "GCD(200, 625) = " and gcd(200, 625)
END
Reveal complete JDK 27 program
public class EuclidGCD {
    // Precondition: a > 0 and b > 0.
    // Postcondition: returns the greatest common divisor of a and b.
    public static int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }

    public static void main(String[] args) {
        System.out.println("GCD(24, 8) = " + gcd(24, 8));
        System.out.println("GCD(200, 625) = " + gcd(200, 625));
    }
}
Euclid's idea: gcd(a, b) = gcd(b, a % b), and gcd(a, 0) = a. The remainder is always smaller than b, so the numbers shrink and the loop must end. If a < b, the first step just swaps them (200 % 625 = 200). The parameters a and b are the method's own copies, so changing them inside gcd does not affect the caller. The precondition asks for positive integers: gcd(0, 0) is undefined, and because Java's % keeps the sign of its left operand, a negative argument can give a negative result.

Model IPO and pseudocode
isCorrect input: two factors and an answer; output: true or false. The game repeats: draw two numbers from 0 to 12, ask, read the answer, stop on a negative answer, otherwise add 1 to the score when isCorrect is true.
METHOD isCorrect(first, second, answer)
    RETURN answer = first * second

START
SET score = 0
LOOP
    first = random 0 to 12, second = random 0 to 12
    DISPLAY "Enter negative number to quit."
    DISPLAY first, " x ", second, " = " (same line as the answer)
    INPUT answer
    IF answer < 0 THEN EXIT LOOP
    IF isCorrect(first, second, answer) THEN score = score + 1
DISPLAY "Your Score is ", score
END
Reveal complete JDK 27 program
import java.util.Random;
import java.util.Scanner;

public class MultiplicationGame {
    // Precondition: none.
    // Postcondition: returns true when answer is equal to first * second.
    public static boolean isCorrect(int first, int second, int answer) {
        return answer == first * second;
    }

    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        Random random = new Random();
        int score = 0;

        while (true) {
            int first = random.nextInt(13);    // 0 to 12
            int second = random.nextInt(13);
            System.out.println("Enter negative number to quit.");
            System.out.print(first + " x " + second + " = ");
            int answer = keyboard.nextInt();
            if (answer < 0) {
                break;                         // a negative answer ends the game
            }
            if (isCorrect(first, second, answer)) {
                score++;
            }
        }
        System.out.println("Your Score is " + score);
    }
}
isCorrect returns a boolean, so the call can be the condition itself: if (isCorrect(first, second, answer)). nextInt(13) gives 0 to 12. The prompt uses println and the question uses print, so the answer is typed on the question's line, as in the sample. The negative answer is tested before scoring, so −1 ends the game without counting as a question. The model assumes whole-number input.

Model IPO and pseudocode
Five small methods. Output: two lists of 20 numbers, 10 per line. Each loop tests 2, 3, 4, … and stops when 20 matches have been printed.
METHOD isPrime(n): n ≥ 2 and no divisor from 2 to √n
METHOD reverse(n): the digits of n in reverse order
METHOD isPalindrome(n): n = reverse(n)
METHOD isPalindromicPrime(n): isPrime(n) AND isPalindrome(n)

    number = number + 1

public class PalindromicPrimeEmirp {
    // Precondition: none.
    // Postcondition: returns true when number is prime (greater than 1, no divisor from 2 to its square root).
    public static boolean isPrime(int number) {
        if (number < 2) {
            return false;
        }
        for (int divisor = 2; divisor * divisor <= number; divisor++) {
            if (number % divisor == 0) {
                return false;
            }
        }
        return true;
    }

    // Precondition: number >= 0.
    // Postcondition: returns the digits of number in reverse order.
    public static int reverse(int number) {
        int reversed = 0;
        while (number > 0) {
            reversed = reversed * 10 + number % 10;
            number /= 10;
        }
        return reversed;
    }

    // Precondition: number >= 0.
    // Postcondition: returns true when number reads the same backwards.
    public static boolean isPalindrome(int number) {
        return number == reverse(number);
    }

    // Postcondition: returns true when number is both prime and a palindrome.
    public static boolean isPalindromicPrime(int number) {
        return isPrime(number) && isPalindrome(number);
    }

    // Postcondition: returns true when number is prime, its reverse is prime,
    //                and it is not a palindromic prime.
    public static boolean isEmirp(int number) {
        return isPrime(number) && isPrime(reverse(number)) && !isPalindromicPrime(number);
    }

    public static void main(String[] args) {
        System.out.println("The first 20 palindromic primes");
        int count = 0;
        for (int number = 2; count < 20; number++) {
            if (isPalindromicPrime(number)) {
                count++;
                System.out.printf("%6d", number);
                if (count % 10 == 0) {
                    System.out.println();
                }
            }
        }

        System.out.println("The first 20 emirps");
        count = 0;
        for (int number = 2; count < 20; number++) {
            if (isEmirp(number)) {
                count++;
                System.out.printf("%6d", number);
                if (count % 10 == 0) {
                    System.out.println();
                }
            }
        }
    }
}
Five methods with one job each, built on one another: isEmirp calls isPrime twice and isPalindromicPrime once. 11 is a palindromic prime, so it is not an emirp even though its reverse is prime. 23 is prime but 32 is not, so 23 is not an emirp. The loops count matches, not candidates: they run until 20 numbers have been found, as in Lab 4's first n primes.
