Random student scores

Randomly generate N student scores (0–100). Prompt the user to enter N, store the scores in an array, then display the list of scores, the highest score, the lowest score, and the average score.

18, 31, 74, 23, 33
Highest score: 74
Lowest score: 18
Average score: 35.80

highestlowest

Browser random draws illustrate the program; they are independent of Java’s Random.

Model IPO and pseudocode

Input: N. Process: create an int array of size N, fill it with random scores, then scan it once for the highest, the lowest, and the sum. Output: the list and the three results.

START
INPUT n
IF n <= 0 DISPLAY "The number of students must be at least 1." and STOP
CREATE score[n]
FOR i = 0 TO n - 1
    score[i] = random integer from 0 to 100
DISPLAY every score
SET highest = score[0], lowest = score[0], sum = 0
FOR i = 0 TO n - 1
    IF score[i] > highest THEN highest = score[i]
    IF score[i] < lowest THEN lowest = score[i]
    sum = sum + score[i]
DISPLAY highest, lowest, sum / n to 2 decimal places
END
Reveal complete JDK 27 program
import java.util.Random;
import java.util.Scanner;

public class ScoreList {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        Random random = new Random();

        System.out.print("Enter the number of students: ");
        int n = keyboard.nextInt();
        if (n <= 0) {
            System.out.println("The number of students must be at least 1.");
            return;
        }

        int[] score = new int[n];
        for (int i = 0; i < n; i++) {
            score[i] = random.nextInt(101);   // 0 to 100
        }

        System.out.println("List of scores");
        for (int i = 0; i < n; i++) {
            System.out.print(score[i] + (i < n - 1 ? ", " : "\n"));
        }

        int highest = score[0], lowest = score[0];   // start from a real score, not 0
        int sum = 0;
        for (int i = 0; i < n; i++) {
            if (score[i] > highest) {
                highest = score[i];
            }
            if (score[i] < lowest) {
                lowest = score[i];
            }
            sum += score[i];
        }

        System.out.println("Highest score: " + highest);
        System.out.println("Lowest score: " + lowest);
        System.out.printf("Average score: %.2f%n", (double) sum / n);
    }
}
The array size comes from the user, so it is created after N is read: new int[n]. nextInt(101) gives 0 to 100; nextInt(100) never gives 100. Start the highest and lowest from score[0], not 0 or 100, so they are always real scores. Cast before dividing: (double) sum / n keeps the fraction. The worksheet does not cover N ≤ 0; the model prints a message, because score[0] would not exist.

Ten non-duplicate random integers

Generate 10 non-duplicate random integers within the range from 0 to 20.

10 non-duplicate random integers within 0 to 20
3, 20, 10, 1, 6, 9, 2, 7, 13, 0

Example run of the model. The worksheet gives no sample run; the ten values and their order change every run.

Every draw

Stored in number[]

Values 0 to 20

storedduplicate, drawn again
Model IPO and pseudocode

Input: none. Process: draw a candidate, search the values already stored, and keep it only when it is new; repeat until ten are stored. Output: the ten values.

START
CREATE number[10], SET count = 0
WHILE count < 10
    candidate = random integer from 0 to 20
    SET duplicate = false
    FOR i = 0 TO count - 1
        IF number[i] = candidate THEN duplicate = true and leave the FOR loop
    IF NOT duplicate THEN
        number[count] = candidate
        count = count + 1
DISPLAY number
END
Reveal complete JDK 27 program
import java.util.Random;

public class UniqueRandom {
    public static void main(String[] args) {
        Random random = new Random();
        int[] number = new int[10];
        int count = 0;                         // how many unique values are stored

        while (count < 10) {
            int candidate = random.nextInt(21);  // 0 to 20

            boolean duplicate = false;           // linear search of the stored values
            for (int i = 0; i < count; i++) {
                if (number[i] == candidate) {
                    duplicate = true;
                    break;
                }
            }

            if (!duplicate) {                    // keep it; otherwise draw again
                number[count] = candidate;
                count++;
            }
        }

        System.out.println("10 non-duplicate random integers within 0 to 20");
        for (int i = 0; i < number.length; i++) {
            System.out.print(number[i] + (i < number.length - 1 ? ", " : "\n"));
        }
    }
}
A for loop that runs exactly ten times is not enough: a duplicate must be drawn again, so the number of draws is unknown in advance. Use while (count < 10) and increase count only when a value is stored. Search only the first count elements: the others are still 0, and 0 is a valid value, so searching the whole array would wrongly reject 0. An alternative is a boolean[] used = new boolean[21], where used[candidate] answers the question in one step. On average about 13 draws are needed for the ten values.

Weekly work hours

Darker cells are longer days. Each row is hours[e]; each column is one day d.
EmployeeMonTueWedThuFriSatSunTotal
Model IPO and pseudocode

Input: N. Process: fill an N × 7 table with random hours, then add each row. Output: the table with one total per employee.

START
INPUT n
IF n <= 0 DISPLAY "The number of employees must be at least 1." and STOP
CREATE hours[n][7]
FOR e = 0 TO n - 1
    FOR d = 0 TO 6
        hours[e][d] = random integer from 1 to 8
DISPLAY the heading: Employee, Mon … Sun, Total
FOR e = 0 TO n - 1
    SET total = 0
    FOR d = 0 TO 6
        DISPLAY hours[e][d]
        total = total + hours[e][d]
    DISPLAY total
END
Reveal complete JDK 27 program
import java.util.Random;
import java.util.Scanner;

public class WorkHours {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        Random random = new Random();

        System.out.print("Enter the number of employees: ");
        int n = keyboard.nextInt();
        if (n <= 0) {
            System.out.println("The number of employees must be at least 1.");
            return;
        }

        int[][] hours = new int[n][7];           // one row per employee, one column per day
        for (int e = 0; e < n; e++) {
            for (int d = 0; d < 7; d++) {
                hours[e][d] = random.nextInt(8) + 1;   // 1 to 8 hours
            }
        }

        String[] day = {"Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"};
        System.out.printf("%-10s", "Employee");
        for (int d = 0; d < 7; d++) {
            System.out.printf("%5s", day[d]);
        }
        System.out.printf("%7s%n", "Total");

        for (int e = 0; e < n; e++) {
            int total = 0;                       // reset for each employee
            System.out.printf("%-10s", "Emp " + (e + 1));
            for (int d = 0; d < 7; d++) {
                System.out.printf("%5d", hours[e][d]);
                total += hours[e][d];
            }
            System.out.printf("%7d%n", total);
        }
    }
}
nextInt(8) + 1 gives 1 to 8, because nextInt(8) gives 0 to 7. Use one row per employee and one column per day: hours[e][d], with hours.length equal to N and hours[e].length equal to 7. Reset total inside the outer loop; declared once before both loops, it would keep growing across employees. Each total must lie between 7 and 56.

Model IPO and pseudocode

Input: the fixed 3 × 3 matrix from the worksheet. Process: copy each element into a second array at its rotated position. Output: both matrices.

START
SET matrix = {{1, 5, 7}, {3, 6, 9}, {5, 3, 8}}, n = 3
DISPLAY matrix
CREATE rotated[n][n]
FOR r = 0 TO n - 1
    FOR c = 0 TO n - 1
        rotated[r][c] = matrix[n - 1 - c][r]
DISPLAY rotated
END
Reveal complete JDK 27 program
public class RotateMatrix {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 5, 7},
            {3, 6, 9},
            {5, 3, 8}
        };
        int n = matrix.length;

        System.out.println("3 by 3 Matrix");
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                System.out.print(matrix[r][c] + (c < n - 1 ? " " : "\n"));
            }
        }

        // Row r of the result is column r of the original, read from the bottom up.
        int[][] rotated = new int[n][n];
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                rotated[r][c] = matrix[n - 1 - c][r];
            }
        }

        System.out.println("After rotates 90 degrees clockwise");
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                System.out.print(rotated[r][c] + (c < n - 1 ? " " : "\n"));
            }
        }
    }
}
Read the original column by column, from the bottom up: column 0 read upwards (5, 3, 1) becomes row 0. That is rotated[r][c] = matrix[n - 1 - c][r]. Write into a second array; copying inside the same array overwrites values that are still needed. The alternative swaps matrix[r][c] with matrix[c][r] (transpose) and then reverses each row. Rotating anticlockwise uses matrix[c][n - 1 - r].

Sort, then compare two searches

Model IPO and pseudocode

Input: the number to search. Process: fill and print the array, bubble sort it into descending order, then run both searches and count their loops. Output: both lists, the result of each search, and the loop counts.

START
CREATE a[20], each a random integer from 0 to 100
DISPLAY a
FOR pass = 1 TO 19                          bubble sort, descending
    FOR i = 0 TO 19 - pass
        IF a[i] < a[i + 1] THEN swap a[i] and a[i + 1]
DISPLAY a
INPUT key
SET loops = 0
FOR i = 0 TO 19                             linear search
    loops = loops + 1
    IF a[i] = key THEN found, leave the loop
DISPLAY found or not found, loops
SET low = 0, high = 19, loops = 0
WHILE low <= high                           binary search
    loops = loops + 1
    middle = (low + high) / 2
    IF a[middle] = key THEN found, leave the loop
    ELSE IF key > a[middle] THEN high = middle - 1
    ELSE low = middle + 1
DISPLAY found or not found, loops
END

import java.util.Random;
import java.util.Scanner;

public class SearchCompare {
    public static void main(String[] args) {
        Random random = new Random();
        Scanner keyboard = new Scanner(System.in);

        int[] a = new int[20];
        for (int i = 0; i < a.length; i++) {
            a[i] = random.nextInt(101);          // 0 to 100
        }
        System.out.println("A list of 20 random integer within 0 to 100");
        for (int i = 0; i < a.length; i++) {
            System.out.print(a[i] + (i < a.length - 1 ? ", " : "\n"));
        }

        // Bubble sort in descending order: move the smaller value to the right.
        for (int pass = 1; pass < a.length; pass++) {
            for (int i = 0; i < a.length - pass; i++) {
                if (a[i] < a[i + 1]) {
                    int hold = a[i];
                    a[i] = a[i + 1];
                    a[i + 1] = hold;
                }
            }
        }
        System.out.println("Array in descending order");
        for (int i = 0; i < a.length; i++) {
            System.out.print(a[i] + (i < a.length - 1 ? ", " : "\n"));
        }

        System.out.print("Enter a number to search: ");
        int key = keyboard.nextInt();

        // Linear search: count every element compared, including the match.
        int linearLoops = 0;
        boolean linearFound = false;
        for (int i = 0; i < a.length; i++) {
            linearLoops++;
            if (a[i] == key) {
                linearFound = true;
                break;
            }
        }
        System.out.println(key + (linearFound ? " found" : " not found"));
        System.out.println("Linear Search - " + linearLoops + " loop(s)");

        // Binary search on a descending array: larger values are on the left.
        int low = 0, high = a.length - 1, binaryLoops = 0;
        boolean binaryFound = false;
        while (low <= high) {
            binaryLoops++;
            int middle = (low + high) / 2;
            if (a[middle] == key) {
                binaryFound = true;
                break;
            } else if (key > a[middle]) {
                high = middle - 1;               // key is further left
            } else {
                low = middle + 1;                // key is further right
            }
        }
        System.out.println(key + (binaryFound ? " found" : " not found"));
        System.out.println("Binary Search - " + binaryLoops + " loop(s)");
    }
}
Descending order flips both comparisons. Bubble sort swaps when a[i] < a[i + 1], and in binary search a key larger than a[middle] lies to the left, so high = middle - 1. Binary search is only valid after the sort. For 20 values, a missing key always costs linear search 20 loops; binary search needs at most 5. With duplicates such as 46, 46, the two searches may stop at different copies; both report found. To check the sample counts, temporarily replace the random values with the worksheet's 20 values.

Pascal triangle in a square matrix

Create Pascal's triangle in a square matrix. Accept an integer from the user and use it as the number of rows of the triangle.

1   4   6   4   1   0
1   5   10  10  5   1

first column and diagonal: 1the two cells addedtheir sum
Model IPO and pseudocode

Input: n. Process: create an n × n matrix of zeros and fill the triangle row by row from the row above. Output: the whole matrix, zeros included.

START
INPUT n
IF n < 1 DISPLAY "The number of rows must be at least 1." and STOP
CREATE pascal[n][n]                         every element starts at 0
FOR r = 0 TO n - 1
    FOR c = 0 TO r
        IF c = 0 OR c = r THEN pascal[r][c] = 1
        ELSE pascal[r][c] = pascal[r - 1][c - 1] + pascal[r - 1][c]
DISPLAY every row of pascal, all n columns
END
Reveal complete JDK 27 program
import java.util.Scanner;

public class PascalMatrix {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter the number of row of Pascal Triangle to generate: ");
        int n = keyboard.nextInt();
        if (n < 1) {
            System.out.println("The number of rows must be at least 1.");
            return;
        }

        int[][] pascal = new int[n][n];          // every element starts at 0
        for (int r = 0; r < n; r++) {
            for (int c = 0; c <= r; c++) {       // only on or below the diagonal
                if (c == 0 || c == r) {
                    pascal[r][c] = 1;            // first column and diagonal
                } else {
                    pascal[r][c] = pascal[r - 1][c - 1] + pascal[r - 1][c];
                }
            }
        }

        System.out.println("The Pascal Triangle with " + n + " row(s)");
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                System.out.printf("%-4d", pascal[r][c]);
            }
            System.out.println();
        }
    }
}
The inner loop stops at c = r; cells above the diagonal are never assigned and keep the default 0, which the worksheet prints. Each value needs the row above, so build the rows in order from the top. Row r adds up to 2r. An int holds every value up to n = 34; the largest value for n = 15 is 3432. Compare with the Week 6 lecture, which stores the same triangle as a ragged array without the zeros.
