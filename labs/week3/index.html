LAB 02 · QUESTION 01

Fahrenheit to Celsius

Read a temperature in Fahrenheit and display Celsius to two decimal places.

Model IPO and pseudocode

Input: Fahrenheit (double). Process: (F − 32) / 1.8. Output: Celsius to two decimals.

START
INPUT fahrenheit
SET celsius = (fahrenheit - 32) / 1.8
DISPLAY celsius to two decimal places
END
Reveal complete JDK 27 program
import java.util.Locale;
import java.util.Scanner;

public class TemperatureConversion {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in).useLocale(Locale.US);
        System.out.print("Temperature in Fahrenheit: ");
        double fahrenheit = keyboard.nextDouble();
        double celsius = (fahrenheit - 32) / 1.8;
        System.out.printf(Locale.US, "Celsius: %.2f%n", celsius);
    }
}

Common mistakes

fahrenheit - 32 / 1.8 divides 32 before subtraction. The equivalent multiplier is (fahrenheit - 32) * (5.0 / 9.0); 5 / 9 is integer division and produces zero. Floating-point rounding can produce very small residues near zero; formatting rounds the displayed result.

Car-loan monthly payment

Apply the exact flat-interest formula supplied in the worksheet.

Principal
Interest

Worksheet model: M = (P − D) × (1 + R × Y / 100) / (Y × 12). R is entered as a percentage, so enter 3 for 3%. This flat-interest exercise does not model an amortizing loan or an effective annual rate.

Model IPO and pseudocode

Input: price, down payment, annual percentage rate, years. Process: calculate financed principal, total flat interest, total repayment, and monthly payment. Output: monthly payment with two decimal places.

START
INPUT P, D, R, Y
SET principal = P - D
SET monthly = principal * (1 + R * Y / 100) / (Y * 12)
DISPLAY monthly to two decimal places
END
Reveal complete JDK 27 program
import java.util.Locale;
import java.util.Scanner;

public class CarLoanPayment {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in).useLocale(Locale.US);
        System.out.print("Car price: ");
        double price = keyboard.nextDouble();
        System.out.print("Down payment: ");
        double downPayment = keyboard.nextDouble();
        System.out.print("Annual interest rate (%): ");
        double rate = keyboard.nextDouble();
        System.out.print("Duration (years): ");
        double years = keyboard.nextDouble();
        double monthly = (price - downPayment) * (1 + rate * years / 100)
                / (years * 12);
        System.out.printf(Locale.US, "Monthly payment: RM %.2f%n", monthly);
    }
}

Assumptions and checks

Use finite values with P ≥ 0, 0 ≤ D ≤ P, R ≥ 0, and Y > 0. The Java model assumes these preconditions; the browser checks them. Integer division can erase the interest fraction if all its operands are integers. Keep these quantities as double. Do not round the intermediate calculation to two decimals; format the final output.

LAB 02 · QUESTION 03

Three random numbers and their average

Generate three integers from 10 to 50 inclusive, then show their sum and average.

Fixed-seed mode models java.util.Random’s algorithm for the same three nextInt calls. Replaying the same seed repeats the values. Unchecked mode uses browser randomness and need not match Java. Duplicate values are allowed.

Try a boundary set before generating

For 10, 10, 50, predict the sum and average. Use 3.0 as the divisor to preserve the fractional part.

Model IPO and pseudocode

Input: no keyboard input. Process: generate three integers, add them, divide the sum by 3.0. Output: the three values, sum, and average to two decimals.

START
GENERATE a, b, c in the inclusive range 10 to 50
SET sum = a + b + c
SET average = sum / 3.0
DISPLAY a, b, c, sum, and average
END
Reveal complete JDK 27 program
import java.util.Locale;
import java.util.Random;

public class RandomStatistics {
    public static void main(String[] args) {
        Random generator = new Random();
        // For repeatable tests, replace the line above with new Random(42L).
        int first = generator.nextInt(41) + 10;
        int second = generator.nextInt(41) + 10;
        int third = generator.nextInt(41) + 10;
        int sum = first + second + third;
        double average = sum / 3.0;
        System.out.printf("Numbers: %d, %d, %d%n", first, second, third);
        System.out.println("Sum: " + sum);
        System.out.printf(Locale.US, "Average: %.2f%n", average);
    }
}
There are 41 integers from 10 through 50. nextInt(41) returns 0–40; adding 10 gives 10–50. The bound is exclusive. The sum is 30–150 and the average is 10–50.
Check a fractional result

10 + 10 + 50 = 70. 70 / 3.0 → 23.33 when displayed with two decimals. 70 / 3 uses integer division first and gives 23. Storing that result in a double does not restore the fraction.

LAB 02 · QUESTION 04

Seconds to hours, minutes, and seconds

Use integer division and remainder to split a total duration.

The worksheet sample is 123456 → 34 hours, 17 minutes, 36 seconds. Hours are a total duration, so they may exceed 23.

Model IPO and pseudocode

Input: total seconds (long). Process: divide by 3600, extract the remaining minutes and seconds. Output: hours, minutes, seconds.

START
INPUT totalSeconds
SET hours = totalSeconds DIV 3600
SET minutes = (totalSeconds MOD 3600) DIV 60
SET seconds = totalSeconds MOD 60
DISPLAY hours, minutes, seconds
END
Reveal complete JDK 27 program
import java.util.Scanner;

public class SecondsToTime {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter the number of seconds: ");
        long totalSeconds = keyboard.nextLong();
        long hours = totalSeconds / 3600;
        long minutes = (totalSeconds % 3600) / 60;
        long seconds = totalSeconds % 60;
        System.out.printf("%d seconds is %d hours, %d minutes and %d seconds%n",
                totalSeconds, hours, minutes, seconds);
    }
}

Check the invariant

For non-negative input, minutes and seconds each lie in 0–59. Reconstruct the input as hours * 3600 + minutes * 60 + seconds. Using totalSeconds / 60 directly as the minute part counts all minutes instead of the remainder after full hours.

LAB 02 · QUESTION 05

Random integer and digit sum

Generate an integer from 0 to 10000 inclusive and add all of its decimal digits.

The input box lets you test boundaries; the downloaded Java task generates its own number. Browser random results need not match Java.

Model IPO and pseudocode

Input: none for the Java task. Process: generate one integer and extract digits with division and remainder. Output: original number and sum of its digits.

START
GENERATE number in the inclusive range 0 to 10000
EXTRACT each digit using place-value division and MOD 10
SET sum = tenThousands + thousands + hundreds + tens + ones
DISPLAY number and sum
END
Reveal complete JDK 27 program
import java.util.Random;

public class DigitSum {
    public static void main(String[] args) {
        Random generator = new Random();
        int number = generator.nextInt(10001);
        int ones = number % 10;
        int tens = (number / 10) % 10;
        int hundreds = (number / 100) % 10;
        int thousands = (number / 1000) % 10;
        int tenThousands = number / 10000;
        int sum = ones + tens + hundreds + thousands + tenThousands;
        System.out.println("Number: " + number);
        System.out.println("Sum of digits: " + sum);
    }
}
The upper limit 10000 has five digits. Four-digit extraction alone would miss its leading 1. This fixed-range solution needs no loops. The maximum digit sum is 36 at 9999, rather than at the largest number.

Trace division and remainder

For 1234: number % 10 → 4; (number / 10) % 10 → 3; (number / 100) % 10 → 2; (number / 1000) % 10 → 1; number / 10000 → 0. Division removes lower place values; remainder isolates the current digit.

LAB 02 · QUESTION 06

Energy needed to heat water

Apply Q = M × (final temperature − initial temperature) × 4184 with consistent units.

Required conversion: read both temperatures in Fahrenheit, then convert them to Celsius for the equation. Following the sample run, read water mass in grams and convert it to kilograms.

The worksheet assumes a specific heat of 4184 J/(kg·°C) and no phase change. For a temperature increase, Q is positive. If final temperature is lower, Q is negative and represents energy released under this model.

Model IPO and pseudocode

Input: mass in grams and initial/final temperatures in Fahrenheit. Process: convert grams to kilograms and Fahrenheit to Celsius, calculate ΔT, then Q. Output: energy in joules.

START
INPUT mass and initial/final temperatures
CONVERT grams to kilograms
CONVERT both Fahrenheit temperatures to Celsius
SET energy = massKg * (finalC - initialC) * 4184
DISPLAY energy in joules
END
Reveal complete JDK 27 program
import java.util.Locale;
import java.util.Scanner;

public class WaterEnergy {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in).useLocale(Locale.US);
        System.out.print("Water mass in grams: ");
        double massGrams = keyboard.nextDouble();
        System.out.print("Initial temperature in Fahrenheit: ");
        double initialF = keyboard.nextDouble();
        System.out.print("Final temperature in Fahrenheit: ");
        double finalF = keyboard.nextDouble();
        double massKg = massGrams / 1000.0;
        double initialC = (initialF - 32) / 1.8;
        double finalC = (finalF - 32) / 1.8;
        double energy = massKg * (finalC - initialC) * 4184;
        System.out.printf(Locale.US, "Energy: %.2f J%n", energy);
        System.out.printf(Locale.US, "Scientific: %.6e J%n", energy);
    }
}

Why conversions matter

55500 g = 55.5 kg. The temperature difference is 12.6°F = 7°C. Therefore Q = 55.5 × 7 × 4184 = 1625484 J, matching the source screenshot. Fahrenheit differences use a factor of 1/1.8; do not subtract 32 from a temperature difference. Both input temperatures must be in Fahrenheit; the equation must use their converted Celsius values.
