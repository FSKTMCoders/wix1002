LAB 04 · QUESTION 01

Factors of an integer

Accept an integer from the user, then display all its factors in increasing order.

Enter an Integer: 24
The factors are: 1, 2, 3, 4, 6, 8, 12, 24

Sample run from the worksheet.

Green tiles divide the number exactly (remainder 0). Try 1, 13, 36, 100, and 0.

Model IPO and pseudocode

Input: one int. Process: test every candidate i from 1 to the number; i is a factor when number % i == 0. Output: the factors separated by commas.

START
INPUT number
IF number <= 0 DISPLAY "Please enter a positive integer" and STOP
DISPLAY "The factors are: 1"
FOR i = 2 TO number
    IF number % i = 0 THEN DISPLAY ", " and i
END
Reveal complete JDK 27 program
import java.util.Scanner;

public class Factors {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter an Integer: ");
        int number = keyboard.nextInt();

        if (number <= 0) {
            System.out.println("Please enter a positive integer.");
            return;
        }

        System.out.print("The factors are: 1");
        for (int i = 2; i <= number; i++) {
            if (number % i == 0) {
                System.out.print(", " + i);
            }
        }
        System.out.println();
    }
}
Printing 1 before the loop makes the comma separator easy: every later factor is printed as “, i”, so there is no trailing comma. The worksheet does not say what to do with 0 or negative numbers; the model asks for a positive integer.
LAB 04 · QUESTION 02

Sum of a series of sums

Accept an integer n, then sum 1 + (1+2) + (1+2+3) + … + (1+2+3+…+n).

Model IPO and pseudocode

Input: n. Process: keep a running term (1 + 2 + … + i) and add each term to the total. Output: the total.

START
INPUT n
SET term = 0, total = 0
FOR i = 1 TO n
    term = term + i
    total = total + term
DISPLAY total
END
Reveal complete JDK 27 program
import java.util.Scanner;

public class SeriesSum {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter n: ");
        int n = keyboard.nextInt();

        long term = 0;    // 1 + 2 + ... + i
        long total = 0;   // sum of all the terms
        for (int i = 1; i <= n; i++) {
            term += i;
            total += term;
        }
        System.out.println("Sum = " + total);
    }
}
A nested loop also works: an inner loop from 1 to i rebuilds each bracket. Reusing the previous term needs only one loop: each bracket is the previous bracket plus i. Check: n = 4 gives 1 + 3 + 6 + 10 = 20, and the formula n(n + 1)(n + 2) / 6 gives the same. long avoids overflow for larger n.

Exam score statistics

Read scores until a negative score is entered, then display the minimum, maximum, average, and standard deviation.

Standard deviation: s = √( (ΣX² − (ΣX)² / N) / (N − 1) ), where N is the number of scores, ΣX their sum, and ΣX² the sum of their squares.

Enter a score [negative score to quit]:75
Enter a score [negative score to quit]:34
Enter a score [negative score to quit]:58
Enter a score [negative score to quit]:12
Enter a score [negative score to quit]:96
Enter a score [negative score to quit]:-1
1095.0
Minimum Score: 12
Maximum Score: 96
Average Score: 55.00
Standard Deviation: 33.09

Sample run from the worksheet. The line 1095.0 is the variance s² printed before the results; the model does not print it.

QuantityValue
Model IPO and pseudocode

Input: scores until a negative sentinel. Process: count, track the minimum and maximum, and accumulate ΣX and ΣX². Output: the four statistics.

START
SET count = 0, sum = 0, sumOfSquares = 0
INPUT score
WHILE score >= 0
    update minimum and maximum
    count = count + 1
    sum = sum + score
    sumOfSquares = sumOfSquares + score * score
    INPUT score
IF count = 0 DISPLAY "No scores entered" and STOP
DISPLAY minimum, maximum, sum / count
IF count > 1 DISPLAY sqrt((sumOfSquares - sum * sum / count) / (count - 1))
END
Reveal complete JDK 27 program
import java.util.Scanner;

public class ScoreStatistics {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        int count = 0, minimum = 0, maximum = 0;
        double sum = 0, sumOfSquares = 0;

        System.out.print("Enter a score [negative score to quit]:");
        int score = keyboard.nextInt();
        while (score >= 0) {
            if (count == 0 || score < minimum) {
                minimum = score;
            }
            if (count == 0 || score > maximum) {
                maximum = score;
            }
            count++;
            sum += score;
            sumOfSquares += (double) score * score;

            System.out.print("Enter a score [negative score to quit]:");
            score = keyboard.nextInt();
        }

        if (count == 0) {
            System.out.println("No scores entered.");
            return;
        }

        System.out.println("Minimum Score: " + minimum);
        System.out.println("Maximum Score: " + maximum);
        System.out.printf("Average Score: %.2f%n", sum / count);
        if (count > 1) {
            double variance = (sumOfSquares - sum * sum / count) / (count - 1);
            System.out.printf("Standard Deviation: %.2f%n", Math.sqrt(variance));
        } else {
            System.out.println("Standard Deviation: needs at least two scores");
        }
    }
}
The sentinel is read twice: once before the loop and again at the end of the body, so −1 is never counted. Start minimum and maximum from the first score (not 0 or 100). The worksheet does not cover N = 0 or N = 1; the formula divides by N − 1, so the model reports that one score has no standard deviation.
LAB 04 · QUESTION 04

Calendar for May and August

Ask for the year and the first day of the year (0 for Sunday, 1 for Monday, …, 6 for Saturday). Display the calendar for May and August.

May

August

Model IPO and pseudocode

Input: year and first day. Process: count the days before 1 May (January to April, with 29 days in February for a leap year) and before 1 August (add May to July); the remainder after dividing by 7 gives the starting weekday. Output: two month grids.

START
INPUT year, firstDay
SET february = 29 IF leap year ELSE 28
SET startMay = (firstDay + 31 + february + 31 + 30) % 7
SET startAugust = (startMay + 31 + 30 + 31) % 7
FOR each month (May, August)
    DISPLAY the title and day names
    DISPLAY start blank cells
    FOR day = 1 TO 31
        DISPLAY day
        IF (start + day) % 7 = 0 THEN start a new line
END
Reveal complete JDK 27 program
import java.util.Scanner;

public class MayAugustCalendar {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter the year: ");
        int year = keyboard.nextInt();
        System.out.print("Enter the first day of the year (0 = Sunday ... 6 = Saturday): ");
        int firstDay = keyboard.nextInt();

        if (firstDay < 0 || firstDay > 6) {
            System.out.println("The first day must be from 0 to 6.");
            return;
        }

        boolean leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
        int february = leap ? 29 : 28;

        // days before 1 May: January to April
        int startMay = (firstDay + 31 + february + 31 + 30) % 7;
        // days before 1 August: add May, June and July
        int startAugust = (startMay + 31 + 30 + 31) % 7;

        for (int month = 1; month <= 2; month++) {
            String name = (month == 1) ? "May" : "August";
            int start = (month == 1) ? startMay : startAugust;

            System.out.println();
            System.out.println("          " + name + " " + year);
            System.out.println(" Sun Mon Tue Wed Thu Fri Sat");
            for (int blank = 0; blank < start; blank++) {
                System.out.print("    ");
            }
            for (int day = 1; day <= 31; day++) {   // May and August both have 31 days
                System.out.printf("%4d", day);
                if ((start + day) % 7 == 0) {
                    System.out.println();
                }
            }
            if ((start + 31) % 7 != 0) {
                System.out.println();
            }
        }
    }
}
The program trusts the first day the user enters. 1 January 2026 is a Thursday (4), so May 2026 starts on Friday and August 2026 on Saturday. Test a leap year too: 2024 starts on Monday (1), and May 2024 starts on Wednesday.
LAB 04 · QUESTION 05

Dice race to 100

Two players take turns to roll a die. The first player to reach more than 100 points wins. A player who rolls a 6 scores 6 points and rolls again.

Player 1
0
Player 2
0

Browser rolls are independent of Java's Random.

Model IPO and pseudocode

Input: none. Process: alternate turns; within a turn, keep rolling while the roll is 6 and the player has not yet passed 100. Output: every roll, running totals, and the winner.

START
SET score[0] = 0, score[1] = 0, player = 0
LOOP
    DO
        roll = random 1 to 6
        score[player] = score[player] + roll
        DISPLAY roll and total
    WHILE roll = 6 AND score[player] <= 100
    IF score[player] > 100 THEN DISPLAY winner and STOP
    player = 1 - player
END
Reveal complete JDK 27 program
import java.util.Random;

public class DiceRace {
    public static void main(String[] args) {
        Random random = new Random();
        int[] score = new int[2];
        int player = 0;     // 0 is Player 1, 1 is Player 2

        while (true) {
            int roll;
            do {
                roll = random.nextInt(6) + 1;   // 1 to 6
                score[player] += roll;
                System.out.println("Player " + (player + 1) + " rolls " + roll
                        + " -> total " + score[player]
                        + (roll == 6 && score[player] <= 100 ? " (rolls again)" : ""));
            } while (roll == 6 && score[player] <= 100);

            if (score[player] > 100) {
                System.out.println("Player " + (player + 1) + " wins!");
                break;
            }
            player = 1 - player;   // switch turns
        }
    }
}
A do-while fits one turn: a player always rolls at least once, and repeats only after a 6. Check for the winner after every turn, and stop the extra rolls once the player has passed 100. “More than 100” means 101 or more; a player on exactly 100 has not won. The two-element score array previews the Week 5 arrays lecture; two int variables work just as well.
LAB 04 · QUESTION 06

Count the digits

Generate a non-negative random integer and display the number of digits in it.

Model IPO and pseudocode

Input: none (a random int from 0 to 2147483646). Process: divide by 10 until the value becomes 0, counting each division. Output: the number and its digit count.

START
SET number = random non-negative int
SET digits = 0, remaining = number
DO
    digits = digits + 1
    remaining = remaining / 10   (integer division)
WHILE remaining != 0
DISPLAY number, digits
END
Reveal complete JDK 27 program
import java.util.Random;

public class DigitCount {
    public static void main(String[] args) {
        Random random = new Random();
        int number = random.nextInt(Integer.MAX_VALUE);   // 0 to 2147483646

        int digits = 0;
        int remaining = number;
        do {                       // do-while: 0 still has one digit
            digits++;
            remaining /= 10;
        } while (remaining != 0);

        System.out.println("Number: " + number);
        System.out.println("Number of digits: " + digits);
    }
}
random.nextInt() can return negative values, so the model uses nextInt(Integer.MAX_VALUE), which returns 0 to 2147483646. A while loop would report 0 digits for the number 0; the do-while counts it as one digit. Expect mostly long numbers: about 53% of draws have 10 digits and about 42% have 9, while only 10 of the 2.1 billion possible values have one digit. Test 0, 9, 10, and 2147483646 directly.
LAB 04 · QUESTION 07

Mortgage amortization table

Calculate a mortgage loan and create the amortization table for an equal total payment plan.

SymbolFormulaMeaning
MP × r / (1 − (1 + r)−N)Monthly payment, with r = i / (12 × 100)
CnM × (1 + r)−(1 + N − n)Principal portion due in month n
LnM − CnInterest due in month n
RnLn / r − CnRemaining principal balance after month n

P is the principal, i the yearly interest rate in %, N the total number of months, and n the month under consideration.

MonthMonthly PaymentPrincipalInterestUnpaid BalanceTotal Interest
Model IPO and pseudocode

Input: P, i, N. Process: compute r and M once, then for each month compute C, L, R and the running total interest. Output: one table row per month.

START
INPUT principal, yearlyRate, months
SET r = yearlyRate / (12 * 100)
SET M = principal * r / (1 - (1 + r)^(-months))
SET totalInterest = 0
FOR n = 1 TO months
    C = M * (1 + r)^(-(1 + months - n))
    L = M - C
    R = L / r - C
    totalInterest = totalInterest + L
    DISPLAY n, M, C, L, R, totalInterest
END
Reveal complete JDK 27 program
import java.util.Scanner;

public class MortgageTable {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter principal amount: ");
        double principal = keyboard.nextDouble();
        System.out.print("Enter interest in %: ");
        double yearlyRate = keyboard.nextDouble();
        System.out.print("Enter total number of month(s): ");
        int months = keyboard.nextInt();

        if (principal <= 0 || yearlyRate <= 0 || months <= 0) {
            System.out.println("Principal, interest and months must be positive.");
            return;
        }

        double r = yearlyRate / (12 * 100);                               // monthly rate
        double payment = principal * r / (1 - Math.pow(1 + r, -months));  // M
        double totalInterest = 0;

        System.out.printf("%-6s%18s%14s%12s%18s%18s%n", "Month", "Monthly Payment",
                "Principal", "Interest", "Unpaid Balance", "Total Interest");
        for (int n = 1; n <= months; n++) {
            double principalDue = payment * Math.pow(1 + r, -(1 + months - n));  // Cn
            double interestDue = payment - principalDue;                          // Ln
            double balance = interestDue / r - principalDue;                      // Rn
            totalInterest += interestDue;
            System.out.printf("%-6d%18.2f%14.2f%12.2f%18.2f%18.2f%n", n, payment,
                    principalDue, interestDue, Math.abs(balance), totalInterest);
        }
    }
}
With P = 10000, i = 4 and N = 12 the model reproduces every row of the worksheet sample: payment 851.50, first interest 33.33, and total interest 217.99. Use Math.pow for the powers, and double, not int, for every money value. The last balance can come out as a tiny negative rounding error such as −0.00; the model prints its absolute value. The formula divides by r, so the model requires a positive interest rate.
LAB 04 · QUESTION 08

The first n prime numbers

Generate the first n prime numbers, where n is a random integer within 0 to 100.

Model IPO and pseudocode

Input: none (n is random from 0 to 100). Process: test candidates 2, 3, 4, … for primality until n primes are found. A candidate is prime when no divisor from 2 to √candidate divides it. Output: the primes, ten per line.

START
SET n = random 0 to 100
SET found = 0, candidate = 2
WHILE found < n
    SET prime = true
    FOR divisor = 2 WHILE divisor * divisor <= candidate
        IF candidate % divisor = 0 THEN prime = false, BREAK
    IF prime THEN found = found + 1, DISPLAY candidate
    candidate = candidate + 1
END
Reveal complete JDK 27 program
import java.util.Random;

public class FirstPrimes {
    public static void main(String[] args) {
        Random random = new Random();
        int n = random.nextInt(101);   // 0 to 100
        System.out.println("n = " + n);

        int found = 0;
        int candidate = 2;
        while (found < n) {
            boolean prime = true;
            for (int divisor = 2; divisor * divisor <= candidate; divisor++) {
                if (candidate % divisor == 0) {
                    prime = false;
                    break;
                }
            }
            if (prime) {
                found++;
                System.out.print(candidate + (found % 10 == 0 ? "\n" : " "));
            }
            candidate++;
        }
        if (n % 10 != 0) {
            System.out.println();
        }
    }
}
The outer loop is sentinel-like: we do not know in advance how many candidates to test, only how many primes to find, so a while loop fits. The inner loop stops at √candidate because any larger factor pairs with a smaller one already tested. n can be 0; then nothing is printed. The 100th prime is 541.
