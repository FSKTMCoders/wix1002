Java model: Exercise09.java

import java.util.*;

public class Exercise09 {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        keyboard.useLocale(Locale.US);
        Random generator = new Random();
        String pageText = keyboard.nextLine();
        String keyword = keyboard.nextLine().trim().toLowerCase(Locale.ROOT);
        if (!keyword.matches("[a-z0-9_]+")) {
            System.out.println("Enter one English keyword");
        } else {
            String[] words = pageText.toLowerCase(Locale.ROOT)
                    .split("[^a-z0-9_]+");
            int frequency = 0;
            for (String word : words) {
                if (word.equals(keyword)) {
                    frequency++;
                }
            }
            System.out.println("Frequency: " + frequency);
        }
    }
}

EXERCISE 12 · PART II

Guess the hidden number

Guess a random number generated by the computer.

Assumptions: Choose a fixed target in 1–100 for each game. Accept integer guesses in this range. Give higher/lower hints until correct; generate a new target only when starting a new game.

Your plan

Predict first

If the target is 73 and the guess is 60, which hint is correct?

Experiment

Attempts: 0

A hidden target has been chosen. Enter a guess.
Hint

Keep the target outside the guessing loop. Generate it once, then compare each guess.

Model IPO, pseudocode, flowchart, and Java

IPO model

Input

A fixed random target and repeated guesses

Process

Compare guess with target; repeat while unequal

Output

Higher, Lower, or Correct; attempt count

Pseudocode

START
target ← RANDOM_INTEGER(1, 100)
attempts ← 0
REPEAT
    READ guess
    IF guess < 1 OR guess > 100 THEN
        DISPLAY "Enter 1–100"
    ELSE
        attempts ← attempts + 1
        IF guess < target THEN
            DISPLAY "Higher"
        ELSE IF guess > target THEN
            DISPLAY "Lower"
        ELSE
            DISPLAY "Correct", attempts
        END IF
    END IF
UNTIL guess = target
STOP

Java model: Exercise12.java

import java.util.*;

public class Exercise12 {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        keyboard.useLocale(Locale.US);
        Random generator = new Random();
        int target = generator.nextInt(1, 101);
        int attempts = 0;
        int guess;
        do {
            guess = keyboard.nextInt();
            if (guess < 1 || guess > 100) {
                System.out.println("Enter 1-100");
                continue;
            }
            attempts++;
            if (guess < target) {
                System.out.println("Higher");
            } else if (guess > target) {
                System.out.println("Lower");
            } else {
                System.out.println("Correct in " + attempts + " attempts");
            }
        } while (guess != target);
    }
}
