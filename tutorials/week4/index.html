TUTORIAL 03 · QUESTION 01

Write selection statements

Write statements for each of the following: (a) determine whether 3 × 8 = 27; (b) determine whether an input integer is odd or even; (c) determine whether a character is a capital letter; (d) display two strings in alphabetical order ignoring their case; (e) a switch statement that displays Sunday, Monday, …, Saturday for the input 0, 1, …, 6.

1a · A comparison produces a boolean

Reveal statement for 1a
boolean isEqual = 3 * 8 == 27;
System.out.println("3 x 8 == 27: " + isEqual); // false

Multiplication is evaluated before ==. 3 * 8 is 24, so the comparison is false. Use == to compare; a single = would attempt assignment.

Live checks for 1b–1e

Try −3 and 0 for 1b, g and 5 for 1c, “apple”/“Apple” for 1d, and 7 for 1e.

Reveal statements for 1b and 1c
// 1b: number has been read with Scanner
if (number % 2 == 0) {
    System.out.println(number + " is even");
} else {
    System.out.println(number + " is odd");
}

// 1c
if (ch >= 'A' && ch <= 'Z') {
    System.out.println(ch + " is a capital letter");
} else {
    System.out.println(ch + " is not a capital letter");
}

Test even numbers with % 2 == 0. For negative odd numbers the remainder is −1, so number % 2 == 1 would wrongly report −3 as even. A char compares by its code value, and A–Z are consecutive. Character.isUpperCase(ch) is a library alternative that also accepts capital letters from other alphabets.

Reveal statements for 1d and 1e
// 1d
if (first.compareToIgnoreCase(second) <= 0) {
    System.out.println(first + " " + second);
} else {
    System.out.println(second + " " + first);
}

// 1e
switch (day) {
    case 0:
        System.out.println("Sunday");
        break;
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    case 3:
        System.out.println("Wednesday");
        break;
    case 4:
        System.out.println("Thursday");
        break;
    case 5:
        System.out.println("Friday");
        break;
    case 6:
        System.out.println("Saturday");
        break;
    default:
        System.out.println("Invalid day");
}

compareToIgnoreCase returns a negative number, zero, or a positive number; use only its sign. Every case needs break, or the following day names also print. default handles values outside 0–6. The worksheet spells Saturday as “Satudary”; the model uses the correct spelling.

TUTORIAL 03 · QUESTION 02

Correct the errors

Find the error in each statement, then write a corrected version. Decide whether each original fails to compile or compiles with the wrong meaning.

2a

if (num1 = num2)
    System.out.println("Number 1 is equal to number 2.");
Reveal correction
if (num1 == num2)
    System.out.println("Number 1 is equal to number 2.");

= assigns. For int variables the assignment produces an int, not a boolean, so it does not compile. Use == to compare.

2b

if (x > y > z)
    System.out.println("x is the largest number");
Reveal correction
if (x > y && x > z)
    System.out.println("x is the largest number");

x > y produces a boolean, and Java cannot compare a boolean with z using >, so the original does not compile. Combine two comparisons with &&. x > y && y > z also guarantees that x is largest, but it is stricter: for x = 9, y = 2, z = 5 it is false although 9 is the largest.

2c

String s1, s2;
if (s1==s2)
    System.out.println("They are equal strings.");
else (s1!=s2)
    System.out.println("They are not equal strings.");
Reveal correction
String s1 = "Java", s2 = "Java";
if (s1.equals(s2))
    System.out.println("They are equal strings.");
else
    System.out.println("They are not equal strings.");

Three problems: else does not take a condition (the opposite case is implied); s1 and s2 must be given values before they are read; and == compares references, while equals compares String content. The values are illustrative; read them with Scanner in a full program.

2d

if x>0 or y>0;
    System.out.println("Either x or y is positive");
Reveal correction
if (x > 0 || y > 0)
    System.out.println("Either x or y is positive");

The condition needs parentheses, and Java uses || rather than the word or. Remove the semicolon: if (…); has an empty body, so the message would print every time.

TUTORIAL 03 · QUESTION 04

Find the biggest of three integers

Write Java statements that use the if statement to find the biggest number among three given integers.

Reveal complete JDK 27 program
import java.util.Scanner;

public class BiggestOfThree {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter three integers: ");
        int a = keyboard.nextInt();
        int b = keyboard.nextInt();
        int c = keyboard.nextInt();

        int biggest = a;
        if (b > biggest) {
            biggest = b;
        }
        if (c > biggest) {
            biggest = c;
        }
        System.out.println("The biggest number is " + biggest);
    }
}

Assume the first value is biggest, then compare each remaining value with the current biggest. These are separate if statements, not an else-if chain: both comparisons are always needed.

Alternative: one if-else-if chain
int biggest;
if (a >= b && a >= c) {
    biggest = a;
} else if (b >= c) {
    biggest = b;
} else {
    biggest = c;
}

The first branch needs both comparisons joined with &&. With >= a tie stops at the first of the equal values; either operator gives the correct biggest value, but test ties such as 7, 7, 3 and 7, 3, 7 to confirm.

a, b, cExpected biggestPurpose
3, 9, 59Middle value largest
9, 3, 59First value largest
3, 5, 99Last value largest
7, 7, 77All equal
−2, −9, −5−2Negative values; starting biggest at 0 would be wrong
TUTORIAL 03 · QUESTION 05

Determine a leap year

A leap year is divisible by 4 but not by 100. However, a year divisible by 400 is also a leap year.

Reveal complete JDK 27 program
import java.util.Scanner;

public class LeapYear {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter a year: ");
        int year = keyboard.nextInt();

        boolean isLeap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
        if (isLeap) {
            System.out.println(year + " is a leap year");
        } else {
            System.out.println(year + " is not a leap year");
        }
    }
}

The single boolean expression matches the worksheet sentence: (divisible by 4 AND NOT by 100) OR divisible by 400. The parentheses make the grouping explicit; && is evaluated before || in any case. The flowchart shows an equivalent else-if chain.

Common mistakes

Testing only year % 4 == 0 reports 1900 as a leap year. Writing the 100 rule first in an else-if chain (if (year % 100 == 0) not leap) makes 2000 wrong. These rules describe the Gregorian calendar; the model does not validate years before its adoption.
