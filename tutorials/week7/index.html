1a–1d · What does each declaration create?

Reveal statements for 1a–1d
double[] numbers = new double[12];            // 1a: 12 elements, each 0.0
char[] letters = {'A', 'B', 'C', 'D', 'E'};   // 1b: length 5, counted by the compiler
String[] names = new String[100];             // 1c: indexes 0 to 99, each null
int[][] table = new int[6][2];                // 1d: 6 rows, 2 columns, each 0

1a: double is Java’s usual floating-point type; float[] numbers = new float[12]; is also correct. The size goes after new, never in the declaration: double numbers[12]; does not compile (“']' expected”).

1b: the initialiser list both creates and fills the array. char values use single quotes. A String version, String[] letters = {"A", "B", "C", "D", "E"};, also works but needs double quotes.

1c: new String elements start as null until a name is assigned; calling a method such as names[0].length() before then throws NullPointerException.

1d: the first size is the number of rows and the second the number of columns: table.length is 6 and table[0].length is 2.

1e and 1f · Modify the table yourself

The page applies statements of the form m[row][col] = value; or m[row] = new int[] {…}; in order, like Java. Amber cells changed from 1e. An index outside the array stops the run, as an exception would.

Reveal statements for 1e and 1f
int[][] m = { {6, 9}, {2, 5}, {4, 6} };   // 1e: each inner brace is one row

m[1][1] = 4;   // 1f: row 1, column 1: 5 becomes 4
m[2][0] = 3;   //     row 2, column 0: 4 becomes 3
m[2][1] = 7;   //     row 2, column 1: 6 becomes 7

Only three elements change; row 0 is untouched. Read m[2][0] as “row 2, then column 0 inside that row”. Replacing the whole row with m[2] = new int[] {3, 7}; also works, but m[2] = {3, 7}; does not compile: a brace list without new is allowed only in a declaration.

1g · Display every value of contact

Reveal statements for 1g
for (int k = 0; k < contact.length; k++) {
    System.out.println(contact[k]);   // println: one value per line
}

The worksheet does not give the element type of contact; this loop works for any array type, and the model declares it as a String array. Use contact.length, not a fixed number, so the loop fits any size, and <, not <=, so it stops at the last index. For a String array, the enhanced for loop for (String c : contact) System.out.println(c); also works.

TUTORIAL 05 · QUESTION 02

Correct the errors

Correct the error in each of the following statements. First decide what kind of error it is: does the code fail to compile, or does it compile and then stop with an exception when it runs?

2a

String[] code = {'AAA', 'AAB', 'AAC', 'AAD'};

Reveal correction for 2a
String[] code = {"AAA", "AAB", "AAC", "AAD"};

Single quotes enclose exactly one char, such as 'A'. 'AAA' is not a valid literal, so the compiler reports “unclosed character literal”. String literals use double quotes.

2b

int[] num = new num[10];
for(int k=0; k<=num.length(); k++)
    sum+=num;

After fixing the compile errors, is <= safe?

Reveal correction for 2b
int[] num = new int[10];
int sum = 0;
for (int k = 0; k < num.length; k++)
    sum += num[k];

Five fixes. new num[10] must name the element type: new int[10]. length is a field of an array, not a method, so it has no parentheses (length() belongs to String). sum += num tries to add a whole array; add one element, num[k]. sum must be declared and start at 0. Finally, the indexes are 0 to 9, so the test is k < num.length: with <=, k reaches 10 and the program stops with ArrayIndexOutOfBoundsException (“Index 10 out of bounds for length 10”).

2c

int [][]t = new int[3][];
t[1][2] = 5;

Memory after new int[3][]

Reveal correction for 2c
int[][] t = new int[3][];   // 3 rows that do not exist yet: each t[r] is null
t[1] = new int[3];          // create row 1 with 3 columns
t[1][2] = 5;

// or create every row at once:
int[][] t = new int[3][3];

The original compiles: leaving out the column size is legal, and it is how ragged arrays start. But only the outer array of 3 row references is created, and each reference is null. At run time t[1][2] follows a null reference and throws NullPointerException (“Cannot store to int array … is null”). Create a row before using it.

2d

int i=4;
int []score = new int[5];
score [1] = 78;
score[++i] = 100;

Which index does the last statement use?

Reveal correction for 2d
int i = 4;
int[] score = new int[5];   // valid indexes 0 to 4
score[1] = 78;
score[i] = 100;             // index 4, the last element

The code compiles: the spaces in int []score and score [1] are legal, if untidy. The problem is ++i: the pre-increment changes i to 5 before it is used as the index, and a 5-element array has no index 5, so the program throws ArrayIndexOutOfBoundsException (“Index 5 out of bounds for length 5”). Use score[i]. score[i++] also stores at index 4 and then leaves i as 5.

Values of array marks

Determine the values of each element of array marks. Assume the array was declared as:

int[] marks = new int[5];
int i = 0, j = 1;
marks[i] = 12;
marks[j] = marks[i] + 19;
marks[j-1] = marks[j] * marks [j];
marks[j*3] = marks[i+1];
marks[++j] = marks[i]%5;
marks[2*j] = marks[j-1];

Predict the final values

Trace one statement at a time

Reveal the trace for Question 3

Final values: marks[0] = 961, marks[1] = 31, marks[2] = 1, marks[3] = 31, marks[4] = 31. marks[0] is assigned twice, and the later 961 replaces 12. ++j changes j for every statement after it, so the last statement uses j = 2. Java works out the index on the left before evaluating the right-hand side; neither i nor j leaves the range 0 to 4.

TUTORIAL 05 · QUESTION 04

Count the word “the”

Write the statements that display the number of occurrences of the word "the" (case sensitive) in a string array named sentence.

Reveal statements for Question 4
String[] sentence = {"the", "cat", "and", "The", "dog", "saw", "the", "bird"};
int count = 0;
for (int k = 0; k < sentence.length; k++) {
    if (sentence[k].equals("the")) {   // case sensitive: "The" does not match
        count++;
    }
}
System.out.println("\"the\" occurs " + count + " time(s)");   // 2

Compare String contents with equals. == only checks whether two variables refer to the same String object, so a word read from the keyboard or built while the program runs can contain "the" and still fail an == test. equals is case sensitive, as the question requires; equalsIgnoreCase("the") would also count "The" and "THE". The count starts at 0 before the loop, and a word with punctuation, such as "the,", is a different String. The model treats each element as one word; if each element held a whole sentence, split it first with sentence[k].split(" ") and count inside a nested loop.

TUTORIAL 05 · QUESTION 05

Display in reverse order

Write the statements that display the string array named sentence in reverse order. Each string element must be displayed in reverse order as well.

Reveal statements for Question 5
for (int k = sentence.length - 1; k >= 0; k--) {           // last element first
    for (int c = sentence[k].length() - 1; c >= 0; c--) {   // last character first
        System.out.print(sentence[k].charAt(c));
    }
    if (k > 0) {
        System.out.print(" ");                               // space between words
    }
}
System.out.println();                                        // nuf si avaJ

The outer loop walks the array backwards; the inner loop walks one String backwards. Notice the two different lengths: sentence.length is the array’s field (no parentheses) and sentence[k].length() is a String method. Both loops count down to index 0 inclusive, so the tests use >= 0. Starting at length instead of length - 1 throws an exception.

TUTORIAL 05 · QUESTION 06

Random number in 8 bits

Write the statements that generate 1 random integer within 0–255. Convert the number to binary and store the bits in an 8-bit array. Then, display the binary number.

Browser random numbers illustrate the task; they do not match Java’s Random.

Reveal statements for Question 6
import java.util.Random;

public class RandomBinary {
    public static void main(String[] args) {
        Random random = new Random();
        int number = random.nextInt(256);   // 0 to 255

        int[] bits = new int[8];            // 8 bits: bits[0] is 128, bits[7] is 1
        int value = number;
        for (int k = 7; k >= 0; k--) {
            bits[k] = value % 2;            // remainder is the next bit from the right
            value /= 2;
        }

        System.out.println("Random number: " + number);
        System.out.print("Binary: ");
        for (int k = 0; k < bits.length; k++) {
            System.out.print(bits[k]);
        }
        System.out.println();
    }
}

8 bits hold 2⁸ = 256 different values, 0 to 255, and nextInt(256) returns exactly that range. Each division by 2 produces the next bit from the right (the remainder), so the loop fills the array from index 7 down to 0; printing from index 0 then shows the most significant bit first, with leading zeros. The loop works on a copy, value, so the original number can still be displayed. Check: add the place values of the 1 bits, for example 202 = 128 + 64 + 8 + 2 = 11001010.
