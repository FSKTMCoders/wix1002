TUTORIAL 06 · QUESTION 1A

Maximum of three integers

Define a static method that returns the maximum number from 3 integer parameters.

Reveal the method for 1a
// 1a. Postcondition: returns the largest of a, b and c.
static int max3(int a, int b, int c) {
    int max = a;
    if (b > max) {
        max = b;
    }
    if (c > max) {
        max = c;
    }
    return max;
}

// a call from main:
int largest = max3(4, 9, 7);   // 9

Three int parameters, an int return type. Start with the first value as the “best so far”, then let each other value replace it only if it is larger. Ties are fine: max3(5, 5, 1) returns 5. Test with negative numbers (max3(-3, -1, -2) is −1): a method that starts max at 0 would wrongly return 0. A shorter version is return Math.max(a, Math.max(b, c));

TUTORIAL 06 · QUESTION 1B

Is it a square number?

Define a static method that determines whether the given integer is a square number.

A square number is an integer times itself: 0, 1, 4, 9, 16, 25, … “Determine whether” means the method answers yes or no, so it returns a boolean.

Reveal the method for 1b
// 1b. Postcondition: returns true if n is a square number (0, 1, 4, 9, 16, ...).
static boolean isSquare(int n) {
    if (n < 0) {
        return false;                        // no negative number is a square
    }
    long root = Math.round(Math.sqrt(n));    // nearest whole number to the square root
    return root * root == n;                 // long: root * root cannot overflow
}

// a call from main:
if (isSquare(49)) {
    System.out.println("49 is a square number");
}

Math.sqrt returns a double, such as 3.872983346207417 for 15. Math.round takes the nearest whole number (4), and squaring it again (16 ≠ 15) checks the answer with exact integer arithmetic instead of comparing doubles. root is a long so that root * root cannot overflow near Integer.MAX_VALUE (46341² is larger than any int). Negative numbers are never squares.

TUTORIAL 06 · QUESTION 1C

Combinations C(n, k)

Define a static method used to compute the combination function C(n, k). C(n, k) gives the number of different k-element subsets that can be found in a given set of n elements: C(n, k) = n! / (k! (n − k)!).

Reveal the methods for 1c
// 1c. Precondition: 0 <= k <= n <= 20 (20! is the largest factorial that fits in a long).
//     Postcondition: returns C(n, k) = n! / (k! (n - k)!).
static long combination(int n, int k) {
    return factorial(n) / (factorial(k) * factorial(n - k));
}

// Precondition: 0 <= n <= 20. Postcondition: returns n! (0! is 1).
static long factorial(int n) {
    long result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}

// a call from main:
System.out.println(combination(5, 2));   // 10

The formula needs n! three times, so a helper method factorial is written once and called three times: exactly the reuse that methods are for. Factorials grow very fast: 13! no longer fits in an int, and 21! no longer fits in a long, so this version states the precondition n ≤ 20. Checks: C(5, 2) = 10, C(10, 3) = 120, C(20, 10) = 184756, and C(n, 0) = C(n, n) = 1.

Going further: the same value can be built without large factorials, result = result * (n - i) / (i + 1) for i from 0 to k − 1. Each step stays a whole number, so it works for much larger n.

TUTORIAL 06 · QUESTION 1D

Is it a pentagonal number?

Define a static method used to determine whether the parameter is a pentagonal number. A pentagonal number is a figurate number that extends the concept of triangular and square numbers to the pentagon: Pn = ½ n(3n − 1).

The first terms are P1 = 1, P2 = 5, P3 = 12, P4 = 22, P5 = 35, …

Reveal the method for 1d
// 1d. Postcondition: returns true if x is a pentagonal number 1, 5, 12, 22, 35, ...
static boolean isPentagonal(int x) {
    if (x < 1) {
        return false;                        // the sequence starts at P1 = 1
    }
    long p = 0;
    for (long n = 1; p < x; n++) {
        p = n * (3 * n - 1) / 2;             // Pn = n(3n - 1) / 2, always a whole number
    }
    return p == x;                           // stopped exactly on x, or jumped past it
}

// a call from main:
System.out.println(isPentagonal(35));   // true

Generate P1, P2, P3, … until the value reaches or passes x. If the loop stops exactly on x, x is pentagonal; if it jumps past x, it is not. n(3n − 1) is always even (when n is odd, 3n − 1 is even), so dividing by 2 never loses a fraction and integer arithmetic is exact. long keeps the last term from overflowing for x close to Integer.MAX_VALUE. This model treats 0 and negative numbers as not pentagonal because the sequence starts at P1 = 1.

TUTORIAL 06 · QUESTION 1E

Count letters and digits

Define a static method that displays the number of letters and the number of digits of a String parameter.

Teal tiles are letters, gold tiles are digits, and white tiles are neither.

Reveal the method for 1e
// 1e. Precondition: text is not null.
//     Postcondition: prints how many letters and how many digits text contains.
static void countLettersDigits(String text) {
    int letters = 0, digits = 0;
    for (int i = 0; i < text.length(); i++) {
        char ch = text.charAt(i);
        if (Character.isLetter(ch)) {
            letters++;
        } else if (Character.isDigit(ch)) {
            digits++;
        }                                    // spaces and punctuation are neither
    }
    System.out.println("Letters: " + letters + ", digits: " + digits);
}

// a call from main:
countLettersDigits("WIX1002 Java 27!");   // Letters: 7, digits: 6

The method displays its result, so it is void and prints inside the method. Character.isLetter and Character.isDigit are static methods of the class Character: you call them with the class name, as in the Week 7 lecture. Spaces, punctuation and symbols are counted as neither. An empty string prints 0 and 0.

TUTORIAL 06 · QUESTION 1F

Fill an array with random numbers

Define a static void method that generates 10 random numbers within 0 to 100 to the method’s parameter. The random numbers can be accessed by the main method.

A void method returns nothing, so the numbers must reach main another way: through an array parameter. The method receives a copy of the reference, follows it, and fills main’s own array.

Browser random numbers illustrate the idea; they do not match Java’s Random.

Reveal the method for 1f
// 1f. Precondition: values is not null (main passes an array of 10 elements).
//     Postcondition: every element of the caller's array is a random number from 0 to 100.
static void fillRandom(int[] values) {
    for (int i = 0; i < values.length; i++) {
        values[i] = RANDOM.nextInt(101);     // 0 to 100 inclusive
    }
}

// in main:
int[] numbers = new int[10];
fillRandom(numbers);          // numbers now holds 10 random values
System.out.println(numbers[0]);

nextInt(101) gives 0 to 100 inclusive. This works because of call-by-value with a reference type (Week 7): values is a copy of the reference in numbers, so both lead to the same array. If the method first did values = new int[10];, it would fill a different array, and main would still see ten zeros. The method declares Random once (a static field in the model) rather than creating a new one on every call.

TUTORIAL 06 · QUESTION 1G

Area and circumference

Define a static void method that returns the area and the circumference of a circle given the argument is radius. Area = πr² and Circumference = 2πr.

A void method cannot use return to send back a value, and a method can return only one value anyway. The worksheet’s idea is that the method “returns” two results to the caller: as in 1f, it stores them in an array that the caller passes in, and the caller reads them afterwards.
Reveal the method for 1g
// 1g. Precondition: radius >= 0 and result has at least 2 elements.
//     Postcondition: result[0] is the area and result[1] is the circumference.
static void circle(double radius, double[] result) {
    result[0] = Math.PI * radius * radius;   // area = pi r^2
    result[1] = 2 * Math.PI * radius;        // circumference = 2 pi r
}

// in main:
double[] circleResult = new double[2];
circle(2.5, circleResult);
System.out.printf("area %.2f, circumference %.2f%n",
        circleResult[0], circleResult[1]);   // area 19.63, circumference 15.71

Use Math.PI, not 3.14. Radius 1 gives area 3.14 and circumference 6.28; radius 2.5 gives 19.63 and 15.71. An alternative design, often clearer, is two value-returning methods: static double area(double r) and static double circumference(double r). The array version is what a void method requires.

TUTORIAL 06 · QUESTION 1H

First number generated twice

Define a static method that generates random numbers within 0 – 10. The method will return the first random number that is generated twice.

Top row: seen[0] to seen[10]. Bottom row: the draws in order. Browser random numbers do not match Java’s Random.

Reveal the method for 1h
// 1h. Postcondition: returns the first number from 0 to 10 that is generated twice.
static int firstRepeat() {
    boolean[] seen = new boolean[11];        // seen[v] becomes true once v is drawn
    while (true) {
        int value = RANDOM.nextInt(11);      // 0 to 10
        if (seen[value]) {
            return value;                    // drawn before: the first repeat
        }
        seen[value] = true;
    }
}

// a call from main:
System.out.println("First repeat: " + firstRepeat());

A boolean[11] remembers which of the 11 possible values have appeared: index v stands for the value v. The method returns as soon as a value is drawn whose flag is already true. There are only 11 different values, so by the 12th draw at least one must have repeated (the pigeonhole principle): the loop always ends, after at most 12 draws. while (true) is safe here because the return inside it is guaranteed to run.

TUTORIAL 06 · QUESTION 02

Three numbers in decreasing order

Write a program that consists of a method that can display three numbers in decreasing order.

Reveal the program for Question 2
import java.util.Scanner;

public class DecreasingOrder {
    // Postcondition: prints a, b and c from largest to smallest, separated by spaces.
    // a, b and c are copies, so swapping them does not change the caller's variables.
    static void printDecreasing(int a, int b, int c) {
        int hold;
        if (a < b) { hold = a; a = b; b = hold; }   // now a >= b
        if (a < c) { hold = a; a = c; c = hold; }   // now a is the largest
        if (b < c) { hold = b; b = c; c = hold; }   // now b >= c
        System.out.println(a + " " + b + " " + c);
    }

    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter three integers: ");
        int x = keyboard.nextInt();
        int y = keyboard.nextInt();
        int z = keyboard.nextInt();

        System.out.print("Decreasing order: ");
        printDecreasing(x, y, z);
    }
}

Three compare-and-swap steps sort three values: after the first two steps a holds the largest, and the third puts b and c in order. Ties need no special case. The swaps change only the method’s own copies of the arguments: main’s x, y and z keep their values (call-by-value). Sample runs: 3 1 2 → 3 2 1; 5 5 1 → 5 5 1; −1 −2 −3 → −1 −2 −3.
