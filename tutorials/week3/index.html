TUTORIAL 02 · QUESTION 01

Knowledge is Power

Display Knowledge is Power (a) in one line using three Java statements; (b) in three lines using one Java statement.

Reveal Java and explanation
// (a) Three statements on one output line
System.out.print("Knowledge ");
System.out.print("is ");
System.out.println("Power");

// (b) One statement on three output lines
System.out.println("Knowledge\nis\nPower");

print does not end the output line. println adds a final line separator. Each \n inside the string starts a new line. Spaces must be written explicitly between words.

START

DISPLAY "is " without a newline
DISPLAY "Power" followed by a newline
END
Part (b) pseudocode and flowchart
START
DISPLAY "Knowledge", newline, "is", newline, "Power"
END

Quotation marks inside a string

Write one Java statement that displays exactly:

"RAM" is called Random Access Memory.

Reveal model answer
System.out.println("\"RAM\" is called Random Access Memory.");

\" represents a double quote inside a Java string literal. The outer quotes delimit the string; they are not printed.

TUTORIAL 02 · QUESTION 03

Repair output statements

Find and explain each error. Part (c) depends on the intended output, so distinguish valid syntax from a display mistake.

3a

System.Println("Hello Java!");
Compare with a correction
System.out.println("Hello Java!");

Use System.out.println: out identifies the output stream and println starts with lowercase p.

3b

System.out.println("Introduction to Java!")
Compare with a correction
System.out.println("Introduction to Java!");

Add the terminating semicolon.

3c

System.out.println("\t is the horizontal tab character");
Compare with a correction
System.out.println("\\t is the horizontal tab character");

The supplied line already compiles. It prints an actual tab. If the intended output shows the two literal characters \t, escape the backslash as \\t.

3d

system.out.println("Java is case sensitive!" );
Compare with a correction
System.out.println("Java is case sensitive!");

System must begin with uppercase S. Extra spaces before ) are harmless.

Tab versus literal backslash

Choose a mode.

A tab moves to the next tab stop; its visible width depends on the console.

Reveal declarations and explanations

Body weight commonly needs a fractional value. float is also possible; double is the usual beginner choice.

String url;

URL text needs String, whose name begins with uppercase S.

boolean status = true;

true is a boolean literal; do not put it in quotes.

char letter = 'Z';

TUTORIAL 02 · QUESTION 05

Repair declarations, arithmetic, and input

Correct each snippet and explain whether the original failure occurs during compilation or at run time.

5a

final double AMOUNT = "32.5";
AMOUNT += 10;
System.out.println("The amount is " + AMOUNT);
Reveal one valid repair
final double AMOUNT = 32.5;
double updatedAmount = AMOUNT + 10;
System.out.println("The amount is " + updatedAmount);

"32.5" is a String, not a double. final prevents reassignment, including +=. This repair keeps AMOUNT constant and stores 42.5 in another variable. If the task instead needs a mutable amount, remove final and initialise double amount = 32.5; before amount += 10.

5b

string chapter = 'Summary';
System.out.println(chapter);
Reveal one valid repair
String chapter = "Summary";
System.out.println(chapter);

String is capitalised. A string uses double quotes; single quotes denote one char.

5c

int num;
++num++;
num1 = num;
Reveal one valid repair
int num = 0;
++num;
int num1 = num;

A local variable needs a value before reading it. ++num++ is not a valid increment target. num1 must also be declared. The worksheet does not specify an initial value or intended increment count; this is one consistent repair that increments once. For two increments, use two separate statements.

5d

int num = 3000;
System.out.printf("%4.2f\n", num);
Reveal one valid repair
int num = 3000;
System.out.printf(java.util.Locale.US, "%4.2f%n", (double) num);

%f requires a supported floating-point argument; passing this int compiles but throws IllegalFormatConversionException when run. Casting fixes it. 4 is a minimum width: 3000.00 is longer and prints fully. If integer output is intended, use %d instead.

5e

String contact;
Scanner keyboard = new Scanner(System.out);
contact = keyboard.nextLine();
Reveal one valid repair
import java.util.Scanner; // At the top of the source file

// Inside main:
Scanner keyboard = new Scanner(System.in);
String contact = keyboard.nextLine();

Read keyboard input from System.in. System.out is an output PrintStream and does not match a Scanner constructor. nextLine reads the complete line, including spaces. Import Scanner before the class declaration.

TUTORIAL 02 · QUESTION 06

Calculate BMI

Read weight w in kilograms and height h in metres. Calculate BMI = w / h² and display two decimal places.

INPUT
PROCESS

weight / (height * height)

OUTPUT

This activity demonstrates the formula and numeric formatting. It provides no clinical interpretation. The live model requires positive finite inputs.

Reveal complete JDK 25 program
import java.util.Locale;
import java.util.Scanner;

public class BmiCalculator {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in).useLocale(Locale.US);
        System.out.print("Weight in kg: ");
        double weight = keyboard.nextDouble();
        System.out.print("Height in metres: ");
        double height = keyboard.nextDouble();
        double bmi = weight / (height * height);
        System.out.printf(Locale.US, "BMI: %.2f%n", bmi);
    }
}

The Java model assumes valid numeric input, weight > 0, and height > 0. Scanner uses Locale.US for a decimal dot. Parentheses group the entire denominator. Java uses ^ for bitwise XOR, not exponentiation.

Model IPO, pseudocode, and flowchart

Input · Process · Output

Input: weight and height. Process: square height and divide weight by it. Output: BMI formatted to two decimal places.

START
INPUT weightKg, heightMetres
SET bmi = weightKg / (heightMetres * heightMetres)
DISPLAY bmi to two decimal places
END
Test cases and common mistakes

70 kg and 1.75 m → 22.86. 60 kg and 1.50 m → 26.67. Using centimetres directly, writing weight / height * height, or using integer arithmetic gives the wrong computation. A height of zero is outside the model assumptions.

TUTORIAL 02 · QUESTION 07

Calculate circle area from diameter

Read the diameter. Use radius = diameter / 2 and area = π × radius², with Math.PI.

Reveal complete JDK 25 program
import java.util.Locale;
import java.util.Scanner;

public class CircleArea {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in).useLocale(Locale.US);
        System.out.print("Diameter: ");
        double diameter = keyboard.nextDouble();
        double radius = diameter / 2.0;
        double area = Math.PI * radius * radius;
        System.out.printf(Locale.US, "Area: %.2f%n", area);
    }
}

The model assumes a finite numeric diameter ≥ 0. Dividing by 2.0 makes the intent explicit. Math.PI supplies a double approximation to π. Formatting rounds the displayed value, not the stored area.

Model IPO, pseudocode, and flowchart

Input · Process · Output

Input: diameter. Process: halve the diameter, then calculate π × radius × radius. Output: area in square units, here formatted to two decimals.

START
INPUT diameter
SET radius = diameter / 2
SET area = PI * radius * radius
DISPLAY area
END
Test cases and common mistakes

Diameter 10 → radius 5 → area 78.54. Diameter 2 → radius 1 → area 3.14. Diameter 0 → area 0.00. Treating diameter as radius makes the area four times too large. The two-decimal formatting is a presentation choice; the source does not require it for this question.
