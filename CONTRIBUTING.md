# Contributing

Thank you for helping improve the WIX1002 course website. Start with the [README](README.md), [local development guide](docs/development.md), and [content maintenance guide](docs/content-maintenance.md).

## Report an issue

Open an [issue](https://github.com/FSKTMCoders/wix1002/issues) with:

- The page URL and teaching week; include the tutorial/lab number and question if relevant.
- The expected behaviour and what happened instead.
- Steps or inputs that reproduce the problem, plus the browser or JDK version when relevant.
- A screenshot or short output excerpt if it helps explain the issue.

Keep personal student details and verification documents out of public issues.

## Propose a change

1. Create a branch in your clone, or fork the repository if you do not have write access.
2. Make a focused change and follow the site's teaching-week/worksheet numbering and relative-link conventions.
3. Preview the result locally. Apply the validation checks relevant to your change; run modified Java models using JDK 25.
4. Update the README or relevant guide if availability, controls, or maintenance behaviour changes.
5. Review the diff and open a pull request explaining the problem, resulting behaviour, and validation performed. For visual changes, include screenshots when useful.

Retain original worksheet downloads, embedded assets, and third-party attribution when editing pages. Availability counts and NEW highlights are maintained separately; follow the [release guidance](docs/content-maintenance.md#update-release-cards-and-counts).

Student tutorial answers and lab projects belong in your own forks of the [tutorial repository](https://github.com/FSKTMCoders/wix1002-tutorial-2026-s1) and [lab repository](https://github.com/FSKTMCoders/wix1002-lab-2026-s1), following their READMEs. Use this repository's pull requests for improvements to the course website and documentation.
