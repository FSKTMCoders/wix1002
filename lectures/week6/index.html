The outer array holds references to row arrays.

int[][] marks = new int[4][3];   // 4 rows (students), 3 columns (tests)

WEEK 06 / 05

Traversal order: row by row or column by column

Swap the loops, change the order of visits.

Row-major (rows outside)

for (int row = 0; row < m.length; row++)
    for (int col = 0; col < m[row].length; col++)
        visit(m[row][col]);

Column-major (columns outside)

for (int col = 0; col < m[0].length; col++)
    for (int row = 0; row < m.length; row++)
        visit(m[row][col]);

Traversal explorer

Each cell shows its value m[row][col] and, once visited, the visit number. Both orders visit all 20 cells exactly once; only the order differs. The inner loop variable changes fastest.

The column-major loop uses m[0].length as the column count. That is only safe for a rectangular table; on a ragged array, use row-major order with m[row].length.

WEEK 06 / 06

Row totals and column averages

Which loop is outside decides what you accumulate.

Marks table: click a row or column header

Row total (one student)

int rowTotal = 0;                 // reset for each row
for (int col = 0; col < marks[row].length; col++)
    rowTotal += marks[row][col];

Column average (one test)

int colTotal = 0;                 // reset for each column
for (int row = 0; row < marks.length; row++)
    colTotal += marks[row][col];
double avg = (double) colTotal / marks.length;
Put the accumulator inside the outer loop when you need one total per row or per column. Put it before both loops when you need one grand total.
Full program: MarksTable.java
public class MarksTable {
    public static void main(String[] args) {
        String[] names = {"Aina", "Ben", "Chen", "Devi"};
        String[] tests = {"Quiz", "Mid", "Final"};
        int[][] marks = {
            {78, 66, 90},     // row 0: Aina
            {62, 74, 88},     // row 1: Ben
            {85, 59, 77},     // row 2: Chen
            {71, 80, 64}      // row 3: Devi
        };

        // header row
        System.out.print("Name");
        for (int col = 0; col < tests.length; col++) {
            System.out.print("\t" + tests[col]);
        }
        System.out.println("\tTotal\tAverage");

        // one row per student: the inner loop walks across the columns
        for (int row = 0; row < marks.length; row++) {
            int rowTotal = 0;
            System.out.print(names[row]);
            for (int col = 0; col < marks[row].length; col++) {
                System.out.print("\t" + marks[row][col]);
                rowTotal += marks[row][col];
            }
            double rowAverage = (double) rowTotal / marks[row].length;
            System.out.printf("\t%d\t%.2f%n", rowTotal, rowAverage);
        }

        // column averages: the outer loop chooses the column
        System.out.print("Average");
        for (int col = 0; col < tests.length; col++) {
            int colTotal = 0;
            for (int row = 0; row < marks.length; row++) {
                colTotal += marks[row][col];
            }
            System.out.printf("\t%.2f", (double) colTotal / marks.length);
        }
        System.out.println();

        // highest mark and where it is
        int maxRow = 0, maxCol = 0;
        for (int row = 0; row < marks.length; row++) {
            for (int col = 0; col < marks[row].length; col++) {
                if (marks[row][col] > marks[maxRow][maxCol]) {
                    maxRow = row;
                    maxCol = col;
                }
            }
        }
        System.out.println("Highest mark: " + marks[maxRow][maxCol] + " by "
                + names[maxRow] + " in " + tests[maxCol]
                + " (marks[" + maxRow + "][" + maxCol + "])");
    }
}

WEEK 06 / 07

Common 2D patterns

Maximum, diagonals, a single row or column, and the transpose.

Pattern explorer on a 4 × 4 matrix

Diagonals need one loop

On the main diagonal the row and column are equal, so m[i][i] with a single loop visits all of it. Nested loops with if (row == col) also work, but check n × n cells to use n.

Track the position, not just the value

Keep maxRow and maxCol. The value is then m[maxRow][maxCol], and you can still report where it was.

Transpose into a new array

A transpose of an r × c table is c × r: new int[m[0].length][m.length]. Copying into a new array avoids overwriting values you still need.

Full program: MatrixPatterns.java (includes Pascal's triangle from the next section)
public class MatrixPatterns {
    public static void main(String[] args) {
        int[][] m = new int[4][4];

        // fill 1 to 16 in row-major order
        int value = 1;
        for (int row = 0; row < m.length; row++) {
            for (int col = 0; col < m[row].length; col++) {
                m[row][col] = value++;
            }
        }
        System.out.println("Matrix m");
        for (int[] row : m) {                 // each row is an int[]
            for (int v : row) {
                System.out.printf("%4d", v);
            }
            System.out.println();
        }

        // diagonals: one loop is enough because row and column are linked
        int mainSum = 0, antiSum = 0;
        for (int i = 0; i < m.length; i++) {
            mainSum += m[i][i];
            antiSum += m[i][m.length - 1 - i];
        }
        System.out.println("Main diagonal sum = " + mainSum);
        System.out.println("Anti-diagonal sum = " + antiSum);

        // transpose: row r of m becomes column r of t
        int[][] t = new int[m[0].length][m.length];
        for (int row = 0; row < m.length; row++) {
            for (int col = 0; col < m[row].length; col++) {
                t[col][row] = m[row][col];
            }
        }
        System.out.println("Transpose t");
        for (int[] row : t) {
            for (int v : row) {
                System.out.printf("%4d", v);
            }
            System.out.println();
        }

        // ragged array: Pascal's triangle, row r has r + 1 elements
        int[][] pascal = new int[6][];
        for (int row = 0; row < pascal.length; row++) {
            pascal[row] = new int[row + 1];
            pascal[row][0] = 1;
            pascal[row][row] = 1;
            for (int col = 1; col < row; col++) {
                pascal[row][col] = pascal[row - 1][col - 1] + pascal[row - 1][col];
            }
        }
        System.out.println("Pascal's triangle");
        for (int row = 0; row < pascal.length; row++) {
            for (int col = 0; col < pascal[row].length; col++) {
                System.out.print(pascal[row][col] + " ");
            }
            System.out.println();
        }
    }
}
WEEK 06 / 08

Ragged arrays: rows with their own length

Create the outer array first, then each row separately.

int[][] num = new int[3][];   // 3 rows; every num[r] is still null
num[0] = new int[3];
num[1] = new int[10];
num[2] = new int[5];

// shortcut with an initialiser list
int[][] days = { {1, 2}, {3, 4, 5, 6}, {7} };

Because a 2D array is an array of arrays, nothing forces the rows to have the same length. A table where rows differ is called a ragged (or jagged) array. Until a row is created, num[r] is null, and num[r].length throws NullPointerException.

Ragged array builder

Is this access valid?

Uses the ragged array you built above. Try the last index of each row, one past it, and a negative index.

Rule for ragged arrays: the outer loop uses num.length, and the inner loop must use num[row].length. Column-by-column traversal and fixed column counts are unsafe because a column may not exist in every row.
int total = 0;                                   // count every element
for (int row = 0; row < num.length; row++) {
    for (int col = 0; col < num[row].length; col++) {
        total++;
    }
    System.out.println("Row " + row + " has " + num[row].length + " columns");
}
System.out.println("Elements: " + total);      // 3 + 10 + 5 = 18
Try it first

For int[][] days = { {1, 2}, {3, 4, 5, 6}, {7} }; give days.length, days[1].length, days[2][0], and say what days[2][1] does.

Reveal answer

3 rows; row 1 has 4 elements; days[2][0] is 7; days[2][1] throws ArrayIndexOutOfBoundsException because row 2 has only index 0. Type 2 4 1 into the builder above to check.

WEEK 06 / 09

Ragged arrays in practice: Pascal's triangle

Each row's length depends on its row number.

int[][] pascal = new int[6][];               // 6 rows, no columns yet
for (int row = 0; row < pascal.length; row++) {
    pascal[row] = new int[row + 1];          // row r has r + 1 elements
    pascal[row][0] = 1;
    pascal[row][row] = 1;
    for (int col = 1; col < row; col++)
        pascal[row][col] = pascal[row - 1][col - 1] + pascal[row - 1][col];
}

Pascal's triangle builder

Each element is the sum of the two elements above it. The inner loop starts at 1 and stops before row because the first and last elements are already 1.

Try it first

How many int elements does a 6-row Pascal array hold? Why would for (int col = 0; col < 6; col++) crash when printing it?

Reveal answer

1 + 2 + 3 + 4 + 5 + 6 = 21. A fixed 6 assumes every row has 6 columns; row 0 has only index 0, so pascal[0][1] throws ArrayIndexOutOfBoundsException. Use pascal[row].length.

Beyond two dimensions: int[][][] attendance = new int[14][5][3]; could store 14 weeks × 5 days × 3 classes. The same rule applies: one index and one loop per dimension, and each length belongs to its own level.

WEEK 06 / 10

Part B · Bubble sort: what each pass guarantees

After pass k, the k largest values are in their final places.

Bubble sort repeatedly compares neighbours and swaps any pair that is out of order. The key fact for tracing, testing, and improving it is the pass invariant:

After pass 1 the largest value is at index n − 1. After pass 2 the two largest are at n − 2 and n − 1. After pass k, the last k positions hold the k largest values in order, so at most n − 1 passes are needed.

Pass-by-pass table

AfterArraySwaps
guaranteed final placemoved during this pass

Notice that the array can become sorted before the last pass. The invariant only promises the tail; the front may be sorted early by luck.

Try it first

Write the array after each pass for 5 1 4 2 8.

Reveal answer

Pass 1: 1 4 2 5 8 · Pass 2: 1 2 4 5 8 · Pass 3: 1 2 4 5 8 (no swaps) · Pass 4: unchanged. The array is sorted after pass 2; passes 3 and 4 only confirm it. Type the values above to check.

WEEK 06 / 13

The swap, line by line

Three assignments and a temporary variable.

if (b[i] > b[i + 1]) {
    int hold = b[i];      // 1. keep a copy of the left value
    b[i] = b[i + 1];      // 2. copy the right value left
    b[i + 1] = hold;      // 3. put the saved value right
}
After lineb[i]b[i+1]hold

Wrong: no temporary variable

b[i] = b[i + 1];          // 10 10
b[i + 1] = b[i];          // 10 10 : 29 is lost

Wrong: comparison sign

if (b[i] >= b[i + 1])     // also swaps equal values

The result is still sorted, but equal values are swapped needlessly, so the sort does extra work and no longer keeps equal items in their original order.

Ascending order: swap when b[i] > b[i + 1]. Descending order: swap when b[i] < b[i + 1]. Nothing else changes.

Keeping equal items in their original order is called stability. With a strict > (or <) bubble sort is stable, which matters when you sort records that tie, as in the ranking example later.

WEEK 06 / 14

Improving bubble sort

Skip the sorted tail, and stop when a pass makes no swaps.

for (int pass = 1; pass < b.length; pass++) {
    boolean swapped = false;
    for (int i = 0; i < b.length - pass; i++) {   // 1. skip the sorted tail
        if (b[i] > b[i + 1]) {
            int hold = b[i];
            b[i] = b[i + 1];
            b[i + 1] = hold;
            swapped = true;
        }
    }
    if (!swapped) break;                         // 2. no swaps: already sorted
}

Compare the three versions

VersionInner loopPassesComparisonsSwaps

All three versions make the same swaps and produce the same sorted array. The improvements only remove comparisons that cannot cause a swap.

Full program: BubbleSortCompare.java
public class BubbleSortCompare {
    public static void main(String[] args) {
        // a 2D array of test cases: each row is one array to sort
        int[][] tests = {
            {29, 10, 14, 37, 13},     // random order
            {10, 13, 14, 29, 37},     // already sorted
            {37, 29, 14, 13, 10}      // reversed
        };
        String[] labels = {"Random  ", "Sorted  ", "Reversed"};

        System.out.println("Case     \tVersion\tPasses\tCompares\tSwaps");
        for (int t = 0; t < tests.length; t++) {
            // version 1: basic, 2: skip the sorted tail, 3: tail + early exit
            for (int version = 1; version <= 3; version++) {
                int[] b = new int[tests[t].length];
                for (int i = 0; i < b.length; i++) {
                    b[i] = tests[t][i];          // sort a copy, not the test row
                }

                int passes = 0, compares = 0, swaps = 0;
                for (int pass = 1; pass < b.length; pass++) {
                    passes++;
                    boolean swapped = false;
                    int limit = (version == 1) ? b.length - 1 : b.length - pass;
                    for (int i = 0; i < limit; i++) {
                        compares++;
                        if (b[i] > b[i + 1]) {
                            int hold = b[i];
                            b[i] = b[i + 1];
                            b[i + 1] = hold;
                            swaps++;
                            swapped = true;
                        }
                    }
                    if (version == 3 && !swapped) {
                        break;                   // no swaps: already sorted
                    }
                }
                System.out.println(labels[t] + "\t" + version + "\t" + passes
                        + "\t" + compares + "\t\t" + swaps);
            }
        }
    }
}

WEEK 06 / 15

How much work does bubble sort do?

Count comparisons to compare algorithms without a stopwatch.

Work counter

AlgorithmBest caseWorst case
  • Basic bubble sort always makes (n − 1) × (n − 1) comparisons.
  • Skipping the tail makes (n − 1) + (n − 2) + … + 1 = n(n − 1) / 2 comparisons.
  • Early exit needs only one pass, n − 1 comparisons, if the data is already sorted, but is still about n² / 2 in the worst case (reversed data).

When n doubles, n² grows four times. That is why bubble sort is fine for 20 marks but slow for a million records; later courses meet faster sorts. Java's own Arrays.sort is the practical choice in real programs, but in this course you write the loop yourself so you understand it.

Try it first

Using the skip-the-tail formula, how many comparisons does bubble sort make for 10 values? For 100?

Reveal answer

10 × 9 / 2 = 45, and 100 × 99 / 2 = 4,950. Ten times more data needs about a hundred times more comparisons.

Sorting parallel arrays

When you swap one array, swap its partners too.

Parallel arrays store related data at the same index: names[i] and marks[i] describe the same student. Sorting must keep those pairs together.

Ranking explorer

RankNameMarkCorrect?
Full program: SortByMark.java
public class SortByMark {
    public static void main(String[] args) {
        // parallel arrays: index i describes the same student in both arrays
        String[] names = {"Aina", "Ben", "Chen", "Devi", "Elle", "Faiz"};
        int[] marks = {72, 85, 64, 90, 85, 58};

        // bubble sort in descending order of mark
        for (int pass = 1; pass < marks.length; pass++) {
            for (int i = 0; i < marks.length - pass; i++) {
                if (marks[i] < marks[i + 1]) {      // < gives descending order
                    int holdMark = marks[i];
                    marks[i] = marks[i + 1];
                    marks[i + 1] = holdMark;

                    String holdName = names[i];     // swap the partner too
                    names[i] = names[i + 1];
                    names[i + 1] = holdName;
                }
            }
        }

        System.out.println("Rank\tName\tMark");
        for (int i = 0; i < marks.length; i++) {
            System.out.println((i + 1) + "\t" + names[i] + "\t" + marks[i]);
        }
    }
}

Ben and Elle both have 85. Because the comparison is a strict <, they are never swapped with each other, so Ben stays ahead of Elle as in the original list (a stable sort).

With a 2D table, a whole row can be swapped in three lines because each row is a reference: int[] holdRow = marks[i]; marks[i] = marks[i + 1]; marks[i + 1] = holdRow;. The case study uses this.

WEEK 06 / 17

Part C · Linear search variants

First match, last match, every match, or a count.

Linear search with a choice of goal

Stop early

First and last occurrence break at the first match in their direction of travel.

Never stop early

All positions and counting must look at every element, so they never break: n comparisons every time.

Not found

Start the position at −1 (and the count at 0). If the loop finishes without a match, the starting value is the answer.

Full program: LinearSearchVariants.java (variants, Strings, and 2D)
public class LinearSearchVariants {
    public static void main(String[] args) {
        int[] data = {8, 42, 8, 64, 21, 8, 54};
        int key = 8;

        // first occurrence: stop at the first match
        int first = -1;
        for (int i = 0; i < data.length; i++) {
            if (data[i] == key) {
                first = i;
                break;
            }
        }

        // last occurrence: search from the end
        int last = -1;
        for (int i = data.length - 1; i >= 0; i--) {
            if (data[i] == key) {
                last = i;
                break;
            }
        }

        // count and list every occurrence: no break
        int count = 0;
        System.out.print("All positions of " + key + ":");
        for (int i = 0; i < data.length; i++) {
            if (data[i] == key) {
                count++;
                System.out.print(" " + i);
            }
        }
        System.out.println();
        System.out.println("First = " + first + ", last = " + last + ", count = " + count);

        // searching Strings: compare contents with equals, not ==
        String[] names = {"Aina", "Ben", "Chen", "Devi"};
        String target = "chen";
        int position = -1;
        for (int i = 0; i < names.length; i++) {
            if (names[i].equalsIgnoreCase(target)) {
                position = i;
                break;
            }
        }
        System.out.println(target + " found at index " + position);

        // searching a 2D array: report the row and the column
        int[][] marks = { {78, 66, 90}, {62, 74, 88}, {85, 59, 77}, {71, 80, 64} };
        int find = 88, foundRow = -1, foundCol = -1;
        for (int row = 0; row < marks.length && foundRow == -1; row++) {
            for (int col = 0; col < marks[row].length; col++) {
                if (marks[row][col] == find) {
                    foundRow = row;
                    foundCol = col;
                    break;                  // leaves the inner loop only
                }
            }
        }
        if (foundRow != -1) {
            System.out.println(find + " found at marks[" + foundRow + "][" + foundCol + "]");
        } else {
            System.out.println(find + " is not in the table");
        }
    }
}

WEEK 06 / 18

String search

Why not ==?

For objects such as String, == asks whether two variables refer to the same object. A name typed with Scanner is a new String object, so == can be false even when the letters match. equals compares the characters.

Case and spaces

equals is case-sensitive: "chen" does not equal "Chen". Use equalsIgnoreCase when case should not matter, and trim() on input that may carry spaces.

WEEK 06 / 20

Part D · Binary search step by step

Three pointers, one comparison, half of the range gone.

Binary search keeps one promise, its invariant: if the key is in the array, it lies between index low and index high. Each comparison keeps the promise while discarding half of the range. When low > high the range is empty, so the key is not there.

Read the pointers under the cells: L is low, M is middle, H is high. The bar under the array shows the part that is still being searched. Integer division rounds down: middle of 0 and 13 is 13 / 2 = 6.

Try it first

Switch on predict mode, then search for 58, then for 9 (missing). How many comparisons did each take?

Reveal answer

58: middles 7 (35, go right), 11 (58, found): 2 comparisons. 9: middles 7 (35, left), 3 (17, left), 1 (8, right), 2 (12, left), then low (2) > high (1): 4 comparisons, not found.

import java.util.Scanner;

public class BinarySearchTrace {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[] num = {2, 4, 11, 18, 29, 36, 36, 38, 42, 45,
                     46, 51, 54, 60, 70, 74, 82, 88, 94, 98};   // ascending

        System.out.print("Enter number to search : ");
        int key = input.nextInt();

        int low = 0;
        int high = num.length - 1;
        int position = -1, steps = 0;

        System.out.println("low\thigh\tmiddle\tnum[middle]\tdecision");
        while (low <= high) {
            int middle = (low + high) / 2;
            steps++;
            System.out.print(low + "\t" + high + "\t" + middle + "\t" + num[middle] + "\t\t");
            if (key == num[middle]) {
                System.out.println("found");
                position = middle;
                break;
            } else if (key < num[middle]) {
                System.out.println("go left: high = " + (middle - 1));
                high = middle - 1;
            } else {
                System.out.println("go right: low = " + (middle + 1));
                low = middle + 1;
            }
        }

        if (position != -1) {
            System.out.println("Found in position " + position + " after " + steps + " comparisons");
        } else {
            System.out.println(key + " is not in the array (" + steps + " comparisons)");
        }
    }
}

WEEK 06 / 23

Binary search as a guessing game

Guess the middle; every answer halves what is left.

I will guess your number

Think of a whole number from 1 to 100. Answer honestly: is your number higher or lower than my guess?

Each guess is (low + high) / 2. “Higher” means low = guess + 1, “Lower” means high = guess - 1. From 100 possibilities the range shrinks 100 → 50 → 25 → 12 → 6 → 3 → 1, so 7 guesses always suffice, because 2⁷ = 128 ≥ 100.

Console version: GuessMyNumber.java
import java.util.Scanner;

public class GuessMyNumber {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int low = 1, high = 100, guesses = 0;
        boolean found = false;

        System.out.println("Think of a whole number from 1 to 100.");
        while (low <= high) {
            int guess = (low + high) / 2;            // binary search: try the middle
            guesses++;
            System.out.print("Guess " + guesses + ": is it " + guess
                    + "? Type H (higher), L (lower) or C (correct): ");
            String answer = input.next().toUpperCase();

            if (answer.equals("C")) {
                found = true;
                System.out.println("Got it in " + guesses + " guesses!");
                break;
            } else if (answer.equals("H")) {
                low = guess + 1;                     // discard the lower half
            } else if (answer.equals("L")) {
                high = guess - 1;                    // discard the upper half
            } else {
                System.out.println("Please type H, L or C.");
                guesses--;                           // that try does not count
            }
        }
        if (!found) {
            System.out.println("No number is left: one of the answers was not consistent.");
        }
    }
}
Try it first

How many guesses are enough for a number from 1 to 1,000? From 1 to 1,000,000?

Reveal answer

10 guesses for 1,000 (2¹⁰ = 1,024) and 20 guesses for 1,000,000 (2²⁰ = 1,048,576).

WEEK 06 / 25

Linear or binary search?

Choose by data size, order, and how often you search.

Linear searchBinary search
Data must be sortedNoYes, ascending
Worst-case comparisons for nnabout log₂ n (20 for a million)
Finds the first of several equal keysYes, naturallyNot guaranteed
Works on Strings, 2D arrays, any conditionYesOnly with a sorted order to compare against
Code length and risk of bugsShort and simpleBounds must be exactly right

One search, unsorted data

Use linear search. Sorting first costs about n² / 2 comparisons with bubble sort, far more than one linear search.

Many searches, same data

Sort once, then use binary search every time. The sorting cost is shared by all the searches.

Try it first

An app looks up 1,000 student IDs in a list of 1,000 unsorted students. Compare the worst-case comparisons for (a) 1,000 linear searches and (b) one improved bubble sort plus 1,000 binary searches.

Reveal answer

(a) 1,000 × 1,000 = 1,000,000. (b) Sorting: 1,000 × 999 / 2 = 499,500, plus 1,000 × 10 = 10,000 for the searches, about 509,500. Sorting first wins when there are many searches; with only a few searches, linear search wins.

Full program: StudentRecords.java
import java.util.Scanner;

public class StudentRecords {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[] ids = {3042, 1187, 2750, 1503, 4011};
        String[] names = {"Aina", "Ben", "Chen", "Devi", "Elle"};
        int[][] marks = {               // Quiz, Mid, Final for each student
            {78, 66, 90},
            {62, 74, 88},
            {85, 59, 77},
            {71, 80, 64},
            {90, 82, 95}
        };

        // 1. bubble sort by ID; every swap moves the whole record
        for (int pass = 1; pass < ids.length; pass++) {
            boolean swapped = false;
            for (int i = 0; i < ids.length - pass; i++) {
                if (ids[i] > ids[i + 1]) {
                    int holdId = ids[i];
                    ids[i] = ids[i + 1];
                    ids[i + 1] = holdId;

                    String holdName = names[i];
                    names[i] = names[i + 1];
                    names[i + 1] = holdName;

                    int[] holdRow = marks[i];        // swap row references
                    marks[i] = marks[i + 1];
                    marks[i + 1] = holdRow;
                    swapped = true;
                }
            }
            if (!swapped) {
                break;
            }
        }

        // 2. print the table with each student's average
        System.out.println("ID\tName\tQuiz\tMid\tFinal\tAverage");
        for (int row = 0; row < ids.length; row++) {
            int total = 0;
            System.out.print(ids[row] + "\t" + names[row]);
            for (int col = 0; col < marks[row].length; col++) {
                System.out.print("\t" + marks[row][col]);
                total += marks[row][col];
            }
            System.out.printf("\t%.2f%n", (double) total / marks[row].length);
        }

        // 3. binary search: the IDs are now in ascending order
        System.out.print("Enter student ID : ");
        int key = input.nextInt();
        int low = 0, high = ids.length - 1, position = -1;
        while (low <= high) {
            int middle = (low + high) / 2;
            if (ids[middle] == key) {
                position = middle;
                break;
            } else if (key < ids[middle]) {
                high = middle - 1;
            } else {
                low = middle + 1;
            }
        }

        if (position == -1) {
            System.out.println("No student with ID " + key);
        } else {
            System.out.print(names[position] + " (row " + position + "):");
            for (int col = 0; col < marks[position].length; col++) {
                System.out.print(" " + marks[position][col]);
            }
            System.out.println();
        }
    }
}

WEEK 06 / 29

Key takeaways, practice, and references

Trace by hand first; then let the code and the tests agree.

Multidimensional arrays

An array of arrays. m.length counts rows; m[r].length counts the columns of row r. The outer loop chooses what you total; reset accumulators inside it.

Bubble sort

After pass k the k largest values are final. Skip the sorted tail and stop when a pass makes no swaps. About n² / 2 comparisons in the worst case. Swap partners in parallel arrays.

Linear search

Any order, any type, any condition. Break for first or last; never break for all or count. Use equals for Strings; report row and column in 2D.

Binary search

Sorted data only. Keep the key inside low…high; low <= high, middle ± 1. About log₂ n comparisons: 20 for a million.
