WEEK 05 / 03

Why do we need arrays?

Separate variables do not scale; an index does.

Without an array

int mark1 = 72, mark2 = 85, mark3 = 64;
int mark4 = 90, mark5 = 58;
int total = mark1 + mark2 + mark3
          + mark4 + mark5;
// 200 students → 200 variables?

With an array

int[] mark = {72, 85, 64, 90, 58};
int total = 0;
for (int i = 0; i < mark.length; i++) {
    total += mark[i];
}
// 200 students → same loop

The loop does not change when the class grows. Only the data changes. That is the point of an array: one name, one type, and a numbered position for every value.

Try it first

Name two collections from daily life that would suit an array, and one that would not.

Reveal explanation

Suitable: the daily temperatures of a month (all double), the seat numbers in a lecture hall (all int). Not suitable as one array: a student record holding a name, an age, and a CGPA, because the values have different types. Records like that will be modelled with classes later.

WEEK 05 / 04

What is an array?

A sequence of values of the same type, numbered from zero.

  • An array is a data structure used to process a collection of data of the same type.
  • It is a group of contiguous memory locations that share the same name and type. Each value has a numeric index (subscript).
  • An array of size N is indexed from 0 to N − 1.
  • In Java an array is a reference data type; the new operator constructs it.

WEEK 05 / 07

Index, length, and bounds

Name, then the index in brackets. The first element is always [0].

  • arrayName[0] refers to the first element; arrayName[3] refers to the fourth.
  • Every array knows its own length: arrayName.length (a field, so no parentheses).
  • The last element is arrayName[arrayName.length - 1].
  • Java throws an exception if an index is out of bounds; it never reads past the end.
  • Elements can be primitives or references, such as an array of String objects.

WEEK 05 / 08

Displaying an array: for and for-each

Two loops visit every element.

Index-based for

for (int i = 0; i < arrayName.length; i++)
    System.out.println(arrayName[i]);

Use it when you need the index: to change an element, compare neighbours, or print positions.

Enhanced for (for-each)

for (int value : arrayName)
    System.out.println(value);

Read it as “for each value in arrayName”. It is shorter and cannot go out of bounds, but it gives no index.

Quick debugging view: System.out.println(java.util.Arrays.toString(arrayName)); prints [72, 85, 64, 90, 58]. Printing arrayName itself shows something like [I@1b6d3586, the type and a hash, not the values.
Try it first

Change the index-based loop so it prints the elements from last to first.

Reveal answer
for (int i = arrayName.length - 1; i >= 0; i--)
    System.out.println(arrayName[i]);
WEEK 05 / 09

for-each cannot change the elements

The loop variable is a copy of each element.

Does not work

int[] mark = {60, 70, 80};
for (int m : mark) {
    m = m + 5;     // changes the copy only
}
// mark is still 60 70 80

Works

int[] mark = {60, 70, 80};
for (int i = 0; i < mark.length; i++) {
    mark[i] = mark[i] + 5;   // writes into the array
}
// mark is now 65 75 85

In each for-each iteration, m receives the value of the next element. Assigning to m changes that local variable, never the array. To update an element you must write to mark[i], which needs an index.

Try it first

Which loop would you use to (a) count the marks above 80, (b) replace every negative value with 0?

Reveal answer

(a) for-each is fine: it only reads. (b) Needs the index-based for loop, because it writes back into the array.

import java.util.Random;

public class FemaleCount {
    public static void main(String[] args) {
        Random r = new Random();
        char[] gender = {'M', 'F'};
        char[] student = new char[100];

        // randomly assign 'M' or 'F' to each of the 100 students
        for (int i = 0; i < student.length; i++) {
            student[i] = gender[r.nextInt(gender.length)];
        }

        int female = 0;
        for (char g : student) {
            if (g == 'F') {
                female++;
            }
        }

        System.out.println("Number of female students: " + female);
        System.out.println("Number of male students: " + (student.length - female));
    }
}

r.nextInt(gender.length) returns 0 or 1, which picks 'M' or 'F' from the gender array. The count varies from run to run but is always between 0 and 100, and female + male is always 100.

The simulator uses browser JavaScript randomness to show the idea; it does not reproduce Java's Random sequence.

WEEK 05 / 14

Array variables hold references

Assignment copies the arrow, not the array.

int[] a = {1, 2, 3};
int[] b = a;        // b refers to the SAME array
b[0] = 99;
System.out.println(a[0]);   // 99

int[] c = a.clone();        // a separate copy
c[1] = 50;
System.out.println(a[1]);   // 2

Because arrays are reference types, == compares references: two arrays with the same contents are not == unless they are the same object. Use java.util.Arrays.equals(a, c) to compare contents.

Try it first

After the code above, what does System.out.println(a == b); print? And a == c?

Reveal answer

true, then false. a and b refer to the same object; c is a different object even though its first element is also 99.

Multidimensional arrays

Two indexes: row first, then column.

typeOfArray[]…[] nameOfArray = new typeOfArray[length_1]…[length_n];

double[][] scoreTable = new double[4][5];   // 4 rows, 5 columns
int[][] matrix = { {1, 2}, {4, 5} };          // initialisation

Arrays with two subscripts often represent tables of values arranged in rows and columns. scoreTable.length is the number of rows (4); scoreTable[row].length is the number of columns in that row (5).

Table explorer: click a cell

Nested loops print a table
public class TableDemo {
    public static void main(String[] args) {
        int[][] matrix = { {1, 2, 3}, {4, 5, 6} };   // 2 rows, 3 columns

        for (int row = 0; row < matrix.length; row++) {
            for (int col = 0; col < matrix[row].length; col++) {
                System.out.print(matrix[row][col] + "\t");
            }
            System.out.println();
        }

        // ragged array: each row has its own length
        int[][] num = new int[3][];
        num[0] = new int[3];
        num[1] = new int[10];
        num[2] = new int[5];

        for (int row = 0; row < num.length; row++) {
            System.out.println("Row " + row + " has " + num[row].length + " columns");
        }
    }
}

The outer loop chooses the row; the inner loop walks across its columns. \t separates columns with a tab.

WEEK 05 / 16

Ragged arrays

Different rows can have different numbers of columns.

int[][] num = new int[3][];   // 3 rows, columns not yet created
num[0] = new int[3];
num[1] = new int[10];
num[2] = new int[5];

A two-dimensional array in Java is an array of arrays. Each row is its own array, so each row can have its own length.

num[0] · length 3
000
num[1] · length 10
0000000000
num[2] · length 5
00000
This is why nested loops should use num[row].length, not a fixed column count: a fixed 10 would go out of bounds on rows 0 and 2.

WEEK 05 / 18

Bubble sort: the idea

Compare neighbours; swap the pair if it is in the wrong order.

  • Nested loops make several passes through the array.
  • Each pass compares successive pairs: [0] with [1], [1] with [2], and so on.
  • If a pair is in increasing order, leave it. If it is in decreasing order, swap the values.
  • After each pass, the largest remaining value has “bubbled” to the end.
Try it first

Reveal answer

WEEK 05 / 19

Bubble sort: code and stepper

The outer loop counts passes; the inner loop compares pairs.

// control number of passes
for (int pass = 1; pass < b.length; pass++)
    // control number of comparisons
    for (int i = 0; i < b.length - 1; i++)
        if (b[i] > b[i + 1]) {
            int hold = b[i];       // swap using a temporary variable
            b[i] = b[i + 1];
            b[i + 1] = hold;
        }

Bubble sort stepper

comparedswappedin final place

Why hold? Writing b[i] = b[i + 1]; b[i + 1] = b[i]; copies the same value twice and loses the original b[i]. The temporary variable keeps it.

For n elements the source version always makes (n − 1) × (n − 1) comparisons: 361 for 20 values. Skipping the sorted tail reduces this to n(n − 1)/2 = 190 with the same result.

import java.util.Random;

public class BubbleSortDemo {
    public static void main(String[] args) {
        Random r = new Random();
        int[] b = new int[20];

        for (int i = 0; i < b.length; i++) {
            b[i] = r.nextInt(100);            // 0 to 99
        }
        for (int value : b) {
            System.out.print(value + " ");
        }
        System.out.println();

        // control number of passes
        for (int pass = 1; pass < b.length; pass++) {
            // control number of comparisons
            for (int i = 0; i < b.length - 1; i++) {
                if (b[i] > b[i + 1]) {        // pair in decreasing order: swap
                    int hold = b[i];
                    b[i] = b[i + 1];
                    b[i + 1] = hold;
                }
            }
        }

        System.out.println("Bubble Sort");
        for (int value : b) {
            System.out.print(value + " ");
        }
        System.out.println();
    }
}

Linear search

Check every element, first to last, until the key matches.

  • Works well for small or unsorted arrays.
  • Searches from the first position to the last in a linear progression.
  • Compares each element with the search key.
// inside a method that returns the position
for (int cnt = 0; cnt < arrayName.length; cnt++)
    if (arrayName[cnt] == searchKey)
        return cnt;
return -1;   // key not found

Linear search stepper

−1 is a safe “not found” value because no array index is negative. The return-based snippet belongs inside a method; methods come later in the course, so the full program below uses a position variable and break instead.

import java.util.Random;
import java.util.Scanner;

public class LinearSearchDemo {
    public static void main(String[] args) {
        Random r = new Random();
        Scanner input = new Scanner(System.in);
        int[] num = new int[20];

        for (int i = 0; i < num.length; i++) {
            num[i] = r.nextInt(100);          // 0 to 99
            System.out.print(num[i] + " ");
        }
        System.out.println();

        System.out.print("Enter number to search : ");
        int searchKey = input.nextInt();

        int position = -1;                    // -1 means not found
        for (int cnt = 0; cnt < num.length; cnt++) {
            if (num[cnt] == searchKey) {
                position = cnt;
                break;                        // stop at the first match
            }
        }

        if (position != -1) {
            System.out.println("Found in position " + position);
        } else {
            System.out.println(searchKey + " is not in the array");
        }
    }
}

WEEK 05 / 23

Binary search: halve the range

For large, sorted arrays: look in the middle, then discard half.

  • The array must be in ascending order.
  • Compare the key with the middle element. If equal, done.
  • If the key is smaller, search the lower half; if larger, the upper half.
  • Each comparison eliminates half of the remaining elements.

Binary search stepper

Faded elements have been eliminated. Try an unsorted array such as 50 10 40 20 30 with key 10: binary search may report “not found” even though 10 is present.

WEEK 05 / 24

Binary search: code and cost

Three subscripts: low, middle, high.

int low = 0;                       // low element subscript
int high = arrayName.length - 1;   // high element subscript
int middle;                        // middle element subscript

// loop until low subscript is greater than high subscript
while (low <= high) {
    middle = (low + high) / 2;
    if (key == arrayName[middle])
        return middle;
    else if (key < arrayName[middle])
        high = middle - 1;         // search the lower half
    else
        low = middle + 1;          // search the upper half
}
return -1;   // key not found

Binary search is far faster on large arrays, but it needs sorted data. Sorting first costs time, so for a single search in a small unsorted array, linear search is simpler and fine.

For very large arrays, low + (high - low) / 2 avoids int overflow in low + high. With duplicates (such as the two 36s), binary search returns the position of a matching element, not necessarily the first.

import java.util.Random;
import java.util.Scanner;

public class BinarySearchDemo {
    public static void main(String[] args) {
        Random r = new Random();
        Scanner input = new Scanner(System.in);
        int[] num = new int[20];

        for (int i = 0; i < num.length; i++) {
            num[i] = r.nextInt(100);          // 0 to 99
            System.out.print(num[i] + " ");
        }
        System.out.println();

        // binary search needs ascending order: bubble sort first
        for (int pass = 1; pass < num.length; pass++) {
            for (int i = 0; i < num.length - 1; i++) {
                if (num[i] > num[i + 1]) {
                    int hold = num[i];
                    num[i] = num[i + 1];
                    num[i + 1] = hold;
                }
            }
        }
        System.out.println("Bubble Sort");
        for (int value : num) {
            System.out.print(value + " ");
        }
        System.out.println();

        System.out.print("Enter number to search : ");
        int key = input.nextInt();

        int low = 0;                          // low element subscript
        int high = num.length - 1;            // high element subscript
        int position = -1;

        while (low <= high) {
            int middle = (low + high) / 2;    // middle element subscript
            if (key == num[middle]) {
                position = middle;
                break;
            } else if (key < num[middle]) {
                high = middle - 1;            // search the lower half
            } else {
                low = middle + 1;             // search the upper half
            }
        }

        if (position != -1) {
            System.out.println("Found in position " + position);
        } else {
            System.out.println(key + " is not in the array");
        }
    }
}

Input simulator

Number methods read one token and skip any spaces or line breaks before it, so 19 2500.50 on one line also works. nextLine() reads whatever is left on the current line. In the trap version, nextInt leaves the Enter after 19 behind, so nextLine returns an empty name.

The simulator models these token rules in the browser. Typing abc for the age causes InputMismatchException in Java. Scanner also follows the computer's locale for decimals; a locale that uses commas may reject 2500.50.

WEEK 05 / 28

Scanner and arrays: read marks

Use the input to size the array, then fill it in a loop.

import java.util.Scanner;

public class ReadMarks {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("How many students? ");
        int n = input.nextInt();
        if (n <= 0) {
            System.out.println("Enter at least one student.");
            return;
        }

        int[] marks = new int[n];
        for (int i = 0; i < marks.length; i++) {
            System.out.print("Mark for student " + (i + 1) + ": ");
            while (!input.hasNextInt()) {          // reject text such as "abc"
                System.out.print("Whole numbers only. Try again: ");
                input.next();                      // discard the bad token
            }
            marks[i] = input.nextInt();
        }

        int total = 0, highest = marks[0];
        for (int mark : marks) {
            total += mark;
            if (mark > highest) {
                highest = mark;
            }
        }

        System.out.printf("Average: %.2f%n", (double) total / marks.length);
        System.out.println("Highest: " + highest);
    }
}

Size from input

new int[n] works because the length can be any int expression computed at run time. Check n first: new int[-1] throws NegativeArraySizeException.

Validate with hasNextInt

hasNextInt() looks ahead without reading. next() throws away a bad token so the loop can ask again.

Highest starts at marks[0], not 0, so the code stays correct for any int data, including negatives.

Bonus: palindrome with a char array

Week 4 reversed digits; arrays let us compare both ends directly.

A palindrome reads the same forward and backward: racecar, level, A man, a plan, a canal: Panama. Convert the text to a char[], then move two indexes towards each other.

import java.util.Scanner;

public class PalindromeWord {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter a word or phrase: ");
        String text = input.nextLine();

        // keep letters and digits only, in lower case
        String cleaned = text.toLowerCase().replaceAll("[^a-z0-9]", "");
        char[] letters = cleaned.toCharArray();

        boolean palindrome = true;
        int left = 0;
        int right = letters.length - 1;
        while (left < right) {
            if (letters[left] != letters[right]) {
                palindrome = false;
                break;                    // one mismatch is enough
            }
            left++;
            right--;
        }

        if (palindrome) {
            System.out.println("\"" + text + "\" is a palindrome");
        } else {
            System.out.println("\"" + text + "\" is not a palindrome");
        }
    }
}

Two-pointer explorer

Try racecar, Racecar with the box unticked, “Was it a car or a cat I saw?”, Java, a single letter, and an empty box. The loop stops when left meets or passes right, so the middle character of an odd-length word is never compared with itself.

Bonus: mirror pairs and reversing an array

Index i pairs with index length − 1 − i.

import java.util.Arrays;

public class ReverseArray {
    public static void main(String[] args) {
        int[] digits = {1, 2, 3, 2, 1};

        // compare each mirror pair: index i and index length - 1 - i
        boolean palindrome = true;
        for (int i = 0; i < digits.length / 2; i++) {
            if (digits[i] != digits[digits.length - 1 - i]) {
                palindrome = false;
                break;
            }
        }
        System.out.println(Arrays.toString(digits)
                + (palindrome ? " is a palindrome" : " is not a palindrome"));

        // reverse in place: swap the same mirror pairs
        int[] data = {10, 20, 30, 40, 50};
        for (int i = 0; i < data.length / 2; i++) {
            int hold = data[i];
            data[i] = data[data.length - 1 - i];
            data[data.length - 1 - i] = hold;
        }
        System.out.println("Reversed: " + Arrays.toString(data));
    }
}

WEEK 05 / 35

Key takeaways, practice, and references

Indexes start at 0 and stop at length − 1.

Arrays

Fixed length, one element type, indexes 0 to length − 1, defaults 0, false, or null. Array variables hold references.

Loops over arrays

Use an index-based for loop to write or compare positions; use for-each to read every value.

Sort and search

Bubble sort swaps neighbouring pairs over several passes. Linear search works on any order; binary search needs ascending order and halves the range.

Input and verification

Scanner methods read typed tokens or lines; java.time gives the date and time. Test first, last, missing, single-element, and duplicate cases.
