java --version

--release 25 targets the Java 25 language and API. These examples need no preview options. With a JDK 25 installation, you can also launch this single-file program directly:

How to read the examples: a block containing a public class and main method is a complete program. Other blocks are fragments to place inside main, with any import declarations at the top of the file. Keep alternative fragments separate to avoid duplicate variable declarations.
JDK 25 alternative: a compact source file

JDK 25 supports compact source files and instance main methods as standard features. The same arithmetic can use this shorter form:

void main() {

    double unitPrice = 2.50;
    double total = quantity * unitPrice;
    System.out.printf(java.util.Locale.US,
            "Total: RM %.2f%n", total);

Save this alternative as SnackCompact.java and run java SnackCompact.java. An explicit class declaration and public static void main(String[] args) remain valid in JDK 25. The main course examples use that conventional structure to match Week 1.

WEEK 02 / 04

Variables: type, name, and value

A variable holds a value your program can use or change.

int quantity;              // Declaration
quantity = 3;              // Assignment
double unitPrice = 2.50;    // Initialization
quantity = 4;              // Replace the stored value
BEFOREquantity = 3

The type is int.

STATEMENTquantity = 4;

Evaluate the right side, then store it.

AFTERquantity = 4

The type stays int. The value changes.

A declaration introduces a name and type. Initialization supplies its initial value. Later assignment replaces that value.

A local variable inside a method must receive a value before you read it. Do not rely on default values for local variables.

Use names that make the program easy to read.

RuleValidInvalid or different

Use lower camel case for variables, such as studentName. Capitalize class names, such as SnackCalculator.

Java also permits many Unicode letters and the dollar sign. For these exercises, use clear English letters and digits. A single underscore _ cannot be an ordinary identifier. In JDK 25, it can mark an unnamed variable or pattern in supported contexts, but you cannot read it as a named value. Use meaningful named variables in these exercises.

WEEK 02 / 07

Constants with final

Use a named constant when a value should remain fixed.

final int MIN_SCORE = 0;
final int MAX_SCORE = 100;
final double CM_PER_METRE = 100.0;
double metres = 2.5;
double centimetres = metres * CM_PER_METRE;
// MAX_SCORE = 120; // Compile-time error

final prevents reassignment after initialization. The examples here are constant variables: final primitive values initialized with constant expressions. A final reference cannot be reassigned, but the object it refers to can still change if it is mutable. Uppercase names with underscores are the usual convention for constants.

Try it before revealing the answer

Explain why CM_PER_METRE is clearer than a repeated 100.0. Predict centimetres for metres = 0.01.

Reveal the explanation

The name explains the conversion factor. The expected result is 1.0 centimetre.

Assignment and arithmetic operators

Evaluate the expression before storing its result.

OperatorMeaningExample

int a = 8, b = 3;
System.out.println(a + b); // 11

System.out.println(a * b); // 24
System.out.println(a / b); // 2

= assigns. Later, == compares suitable values for equality. Read score = score + 5 as “calculate the old score plus five, then store it”.

Integer division by zero throws ArithmeticException. Floating-point division by zero may produce infinity or NaN.

Try it before revealing the answer

Evaluate 18 % 5 + 2 * 3 and (18 % 5 + 2) * 3. Write the intermediate values.

Reveal the explanation

18 % 5 gives 3. The first result is 3 + 6 = 9. The second is (3 + 2) × 3 = 15.

This is a focused arithmetic guide, not the full precedence table. The ^ operator does not mean exponentiation in Java.

WEEK 02 / 10

Integer division: a hidden logic error

The operand types determine division before assignment.

int a = 8, b = 3;
double wrong = a / b;             // 2.0
double right = a / 3.0;           // 2.6666666666666665
double alsoRight = (double) a / b;
double tooLate = (double) (a / b); // 2.0

Browser model for bounded integer examples. Java integer division truncates toward zero.

Assigning the result to double cannot recover a fraction already discarded by integer division.
WEEK 02 / 11

Type casting and conversion

Cast before the operation when you need floating-point arithmetic.

int count = 8;
double widened = count;    // 8.0
double value = 8.9;
int narrowed = (int) value; // 8
int negative = (int) -8.9;  // -8
int a = 8, b = 3;
double answer = a / (double) b;

Widening commonly happens automatically, such as int to double. Narrowing often requires an explicit cast and can lose information. Some widening conversions also lose precision, such as converting large long values to double.

Try it before revealing the answer

An AI proposes double average = (65 + 70) / 2;. Predict the value, then correct the expression.

Reveal the explanation

The original stores 67.0. Use (65 + 70) / 2.0 to obtain 67.5. Casting the sum before division also works.

WEEK 02 / 12

Increment, decrement, and compound assignment

Use one update per statement while learning.

int n = 5;
n++;    // 6
--n;    // 5
n += 3; // 8
n *= 2; // 16
Fresh starting valueStatementAssigned resultFinal n
n = 5int x = n++;x = 56
n = 5int y = ++n;y = 66
n = 5int z = n--;z = 54
n = 5int w = --n;w = 44

Postfix supplies the old value as the expression result, then updates the variable. Prefix updates first and supplies the new value.

For these simple int examples, n += 3 has the same numerical effect as n = n + 3. In general, compound assignment includes an implicit conversion to the left-hand type.

WEEK 02 / 13

Strings and concatenation

A String represents a sequence of characters.

String firstName = "Aina";
String lastName = "Ali";
String fullName = firstName + " " + lastName;
System.out.println(fullName); // Aina Ali
System.out.println("Total: " + 2 + 3);   // Total: 23
System.out.println("Total: " + (2 + 3)); // Total: 5
System.out.println(2 + 3 + " items");    // 5 items

The + operator adds numeric operands or concatenates text. These additions evaluate from left to right. Once the left side is a string, following values join it as text.

firstName and firstname are different identifiers. Insert a space when combining names.
Try it before revealing the answer

Predict System.out.println("Average: " + 8 / 3);.

Reveal the explanation

Average: 2. Division happens before concatenation, and both numeric operands are integers.

WEEK 02 / 14

Console input with Scanner

Import the class, create a scanner, then read the expected type.

import java.util.Scanner;
public class ReadNumber {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int number = keyboard.nextInt();
        System.out.println("The number is " + number);
    }
}
MethodReadsInput example
nextInt()An int token42
nextLong()A long token8000000000
nextDouble()A floating-point token2.5
next()One whitespace-delimited tokenAina
nextLine()The remainder of the current lineAina Ali

Simple examples assume valid input. If nextInt() receives abc, 2.5, or an out-of-range integer, it throws InputMismatchException.

Scanner numeric parsing follows its locale. The complete receipt example sets Locale.US to use a dot as the decimal separator.

JDK 25 note: console text encoding

new Scanner(System.in) is valid. When the terminal input encoding differs from the default charset, specify the terminal encoding explicitly:

Scanner keyboard = new Scanner(
        System.in, System.getProperty("stdin.encoding"));

Use this as an alternative declaration. The JDK 25 launcher supplies the standard-input encoding property. Check terminal settings if names containing non-ASCII characters display incorrectly.

WEEK 02 / 15

The nextInt and nextLine trap

Token reading can leave the end of a line behind.

System.out.print("Age: ");
int age = keyboard.nextInt();
keyboard.nextLine(); // Consume remainder of the age line
System.out.print("Full name: ");
String name = keyboard.nextLine();

Input on separate lines

19⏎
Aina Ali⏎
  1. nextInt() reads 19.
  2. The first nextLine() consumes the empty remainder of the age line and its line separator.
  3. The second nextLine() reads Aina Ali.

This pattern expects the name on the next line. If the name is on the age line, the cleanup call discards that text too.

Try it before revealing the answer

What happens without cleanup? How does next() differ from nextLine() for a full name?

Reveal the explanation

Without cleanup, the shown input gives an empty name. next() reads only Aina. nextLine() reads Aina Ali.

WEEK 02 / 16

Console output and escape sequences

Control line breaks and display special characters.

System.out.print("Hello ");
System.out.println("Java");
System.out.println("Next line");
System.out.println("Name\tScore");
System.out.println("Aina\t80");
System.out.println("First\nSecond");
System.out.println("Path: C:\\notes");
System.out.println("She said \"Hello\".");
EscapeMeaning
\nNewline
\tHorizontal tab
\\Literal backslash
\"Literal double quote

print leaves subsequent output on the same line. println adds a line separator. Tabs move to tab stops, so they do not guarantee neatly aligned columns.

JDK 25 alternative: java.lang.IO

The new java.lang.IO class provides simple line-oriented output and input. In a separate compact file named Greeting25.java, you can write:

void main() {
    String name = IO.readln("Full name: ");
    IO.println("Hello, " + name);
}

Run java Greeting25.java. IO.readln returns a whole line of text. Scanner remains useful for the typed numeric input in this lesson. Use one input-reading approach per program. Do not mix IO.readln with Scanner reads from System.in because buffering makes subsequent input behaviour unspecified.

WEEK 02 / 18

Comments that explain the program

Explain intent, assumptions, or a non-obvious step.

/** Demonstrates a distance conversion. */
public class DistanceExample {
    public static void main(String[] args) {
        /*
         * This example uses a fixed,
         * non-negative distance in metres.
         */
        double metres = 2.5;
        // Convert metres to centimetres.
        double centimetres = metres * 100;
        System.out.println(centimetres); // 250.0
    }
}

// continues to the end of the line. /* ... */ spans lines. /** ... */ documents classes or methods for tools such as Javadoc. Comments do not execute. Keep them consistent with the actual code.

Try it before revealing the answer

A comment says “convert metres to centimetres”, but the code divides by 100. Which part needs correction? Give a test.

Reveal the explanation

Multiply by 100. For 2.5 metres, expect 250 centimetres. Division incorrectly gives 0.025.

WEEK 02 / 19

Random numbers and range boundaries

The upper bound of nextInt(bound) is exclusive.

import java.util.Random;
Random generator = new Random();
int anyInteger = generator.nextInt(); // A signed int
int score = generator.nextInt(100);   // 0 to 99
int die = generator.nextInt(6) + 1;    // 1 to 6
int min = 10, max = 20;
int number = generator.nextInt(max - min + 1) + min; // 10 to 20

Model a six-sided die

Ready: possible values 1–6

The browser uses JavaScript randomness. It does not execute Java or reproduce Java Random's sequence.

The inclusive-range formula assumes min ≤ max and that max − min + 1 is a positive int without overflow. nextInt(bound) requires a positive bound.

A few samples cannot prove a range is correct. Explain its possible minimum and maximum from the formula. Random suits these simulations, but not security-sensitive secrets.
Another range form available in JDK 25
int die25 = generator.nextInt(1, 7);   // 1 to 6
int score25 = generator.nextInt(50, 101); // 50 to 100

Here the origin is inclusive and the bound is exclusive. The origin must be less than the bound. This overload comes from RandomGenerator and has been available since Java 17. The arithmetic form above also remains valid in JDK 25.

WEEK 02 / 20

Worked example: a purchase receipt

Combine input, arithmetic, strings, and formatted output.

import java.util.Scanner;
import java.util.Locale;

public class PurchaseReceipt {
    public static void main(String[] args) {
        Scanner keyboard = new Scanner(System.in);
        keyboard.useLocale(Locale.US);
        System.out.print("Full name: ");
        String fullName = keyboard.nextLine();
        System.out.print("Quantity (whole number): ");
        int quantity = keyboard.nextInt();
        System.out.print("Unit price in RM: ");
        double unitPrice = keyboard.nextDouble();
        double total = quantity * unitPrice;
        System.out.println("Customer: " + fullName);
        System.out.printf(Locale.US, "Total: RM %.2f%n", total);
    }
}

Save as PurchaseReceipt.java. This version assumes a non-negative integer quantity and a finite, non-negative price. It does not validate these assumptions.

Vibe coding: from a prompt to checked Java

Connect AI assistance to the Java concepts you have learned.

Vibe coding describes creating or changing software through natural-language requests to AI, often by judging visible results with limited code inspection. In this course, use AI assistance with deliberate code reading and independent checks.

AI can draft

Request a small console program, an explanation, or a hint for one line.

You verify

Check types, formulas, Scanner methods, output formats, and range boundaries.

I am a first-year WIX1002 Java student using JDK 25.
Help me write a console program named AverageMarks.
Read two integer marks using Scanner.
Calculate their average as a double.
Display "Average: " followed by two decimal places.
Assume valid integer inputs from 0 to 100.
Use an explicit public class and public static void main(String[] args).
Use standard Java 25 APIs and language features. No preview features.
Use only variables, arithmetic, Scanner, and printf.
Do not add loops, arrays, or external libraries.
Explain IPO and the division types before giving code.
Include expected results for (65,70), (0,0), and (100,100).
Use Locale.US for predictable decimal formatting.
